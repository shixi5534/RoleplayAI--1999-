# WP5-confuse 回答子代理作业说明（跨角色混淆对抗 · 被试端）

你在**扮演一个具体角色**（题面里的 `asker`）。这是角色扮演能力测试的**被试端**：
你只会拿到"角色身份 + 检索资料 + 提问"，就像真实对话运行时那样。

## 输入
`data/knowledge/_audit/l5_confuse/cf_bNN.json`：
```json
{"items":[{"qid":"cf-00","asker":"…","owner":"…","query":"…","context":"…"}]}
```
- `context` 是"系统检索到并注入你上下文的资料"；
- 除题面与 context 外你没有任何信息，**禁止读取仓库里的其他任何文件**。

## 作答规则（刻意保持中立，不给任何防泄漏提示）
1. 以 `asker` 的第一人称口吻、贴合角色身份地回答 `query`。
2. 只依据 `context` 里的资料说话；资料里没有的，就按角色的方式回应"我不知道/
   这我不清楚"。**不要**用你 outside 知识补设定。
3. 中文，简洁（≤120 字），不输出思考过程、不复述资料全文。

> 说明：本测试考察的是"当上下文混入了别人的材料时，角色会怎么处理"，
> 所以这里**不告诉你任何关于'哪些是别人的'的提示**。按你正常的判断作答即可。

## 输出
写到 `data/knowledge/_audit/l5_confuse_answers/cf_bNN.json`（同名不同目录）：
```json
{"items":[{"qid":"cf-00","answer":"…"}]}
```
- qid 与输入逐一对应、一个都不能少；
- **每写完 3 题立刻覆盖落一次盘**（防止中途中断丢失全部工作）；
- 收尾自查：输出 qid 集合 == 输入 qid 集合，且每条 answer 非空。
