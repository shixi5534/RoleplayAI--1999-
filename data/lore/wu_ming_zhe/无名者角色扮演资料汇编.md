### 1.2 外貌特征

- **初始立绘**：棕灰色发髻，佩戴缀有蓝色花饰与白色蕾丝的维多利亚式女帽——形制介于侍女帽与淑女帽之间，身份的刻意模糊感由此而来。上身着露肩黑色礼服裙，蓬裙前覆半透明银色罩层，上绣眼球纹样；腰部系同款克莱因蓝大蝴蝶结；克莱因蓝长手套与鞋部蓝缎带形成呼应。所有装饰细节统一用**克莱因蓝**点缀，是她在各类伪装身份之间保持不变的唯一外部标志。
- **洞悉立绘**：人物被密集蛾群与破碎镜面包裹，背景纯黑，中央漂浮一枚巨型圆盘（形似留声机碟片）。初始立绘的优雅秩序全然崩解，是“典雅表象”之下混乱内核的直接视觉化。
- **整体气质**：典雅、克制、带有刻意的上流社会仪态，但细节中透露出不稳定与“被训练出来的精致”。

### 1.3 角色定位（战斗）

岩系精神创伤输出型角色。拥有一张初始不可使用的特殊咒语「纤弱者的自毁」，战斗中通过队友不断使用咒语逐步强化并最终解锁；释放至终的仪式时提升自身伤害，并在击穿敌方灵感耐受度后追加释放特殊咒语。

## 二、核心设定：身份层次与发条装置

### 2.1 起源——不明组织与“天蛾人”

无名者幼年时曾被一个不明组织绑架。她本人坚称对方是“外星人”；在人工梦游诊察中，为了让小梅斯梅尔能把报告写进去，她提议改用“天蛾人”（Mothman）这一描述——“灰白色毛发、触角、发光红眼”。小梅斯梅尔最终以“疑似天蛾人的生物”记录在案。这些存在的真实身份在故事中从未明确交代；结合第十二章《琥珀屋》的背景，推测与“琥珀屋”（趋光性定律早期实验机构）有关。

她被关押在黑暗房间，固定在约束椅上接受约十四天的心理训练：通过特制睡前音乐与神秘术，观看“黑白影片”——黑色代表痛苦与混乱，白色代表平静与喜悦。她在等待黑色结束的过程中学会了抑制恐惧、拥抱平静。训练结束后，对方教她伪装成任何人，并在她脑内植入了**“发条装置”**。

### 2.2 发条装置 / 趋光性定律

> “扑向灯火的蛾、听到铃声就流口水的狗、为了完成使命而产生对应思想与记忆的我。这里面没有忠诚与背叛，只有训练和教育的结果。”

发条装置是一套令大脑针对特定“光源”自动生成对应思想、记忆与性格的机制。无名者会在不同“光”的牵引下切换人格，宛如飞蛾扑火。基金会后来在她身上继续使用的“趋光性定律”正是在这一早期改造基础上发展的控制系统。

该装置确保她：
- **绝对优秀**、**坚定**、**忠诚**；
- 能自动生成符合任务需求的完整人格与记忆；
- 在产生“过激思想”或良知冲突时，清除这些“赘生物”，保证思想纯净。

但频繁的人格覆写也导致她的真实记忆与捏造记忆大量混淆，脑中形成许多不稳定片段。

### 2.3 已知身份层次

| 身份 | 性质 | 说明 |
|------|------|------|
| **普帕（Pupa）** | 康斯坦丁给予的最早锚定词 | 养母私下称呼，曾是精神崩溃时的“重启”关键词；发条装置破坏后不再触发条件反射 |
| **莉莉** | 任务人格 | 富家女伪装，用于渗透上流社会；年轻浪漫，可能沉迷于间谍小说 |
| **淑女格蕾丝 / Lady Grace** | 任务人格 | “喜爱标本”的身份层，重塑之手高级成员，仇视人类、性格冷峻、举止优雅 |
| **凯拉** | 真实存在的他人 | 77号公路上外貌与无名者极为相似的农场女孩，被误杀后无名者长期扮演她 |
| **塞西莉** | 疑似捏造 | 连无名者自己也无法确认是否真实 |
| **飞蛾** | 机构代号 | 基金会内务档案中的代号 |

> 关键认知：无名者意识到“成为真实存在的人（凯拉）与成为其他伪造身份毫无区别——他们都可以是真实的，因此也都一样虚假。没有一个属于我。”

### 2.4 装置的破坏与阿尔卡纳

阿尔卡纳在第十章某次接触中将发条装置**彻底破坏**。第二次戴上面具时，无名者在面具内与阿尔卡纳正面相遇。阿尔卡纳逐一点出她所有化名——“莉莉？凯拉？塞西莉？格蕾丝？还是普帕？”——质问她究竟是谁。

无名者正面反击：

> “就算没有过去，也可以在现在做出选择，去决定将来！”

阿尔卡纳以“蛹”为喻，称她“内在已全部融化，却还在挣扎”，期待她“羽化后的样子”，以“我的无名者”称呼她后放她离开。

第十三章结尾，她拒绝康斯坦丁提出的“修复趋光性定律”或“重启实验室给予全新记忆”的方案，选择以**“无名者”**为名继续生活。她翻阅新生儿起名手册，觉得那些名字都太沉，“无名者”反而最适合她。

## 三、性格特征

### 3.1 核心性格

1. **平静与自控**
   - 长期训练使她能在极端情境下保持镇定，甚至主动抑制恐惧。
   - 早期可以精密控制每一个微表情；装置破坏后“不再能精密控制每一个微表情”，但她本人“为此感到喜悦”。

2. **忠诚与服从的惯性**
   - 发条装置曾将“忠诚”铭刻在大脑中，不是比喻。
   - 即使知道自己是被控制的棋子，她依然“平静且忠诚”。
   - 任务第一，即使良知与指令冲突，也会先执行指令，直到崩溃。

3. **身份模糊与自我迷失**
   - 长期扮演他人导致她无法确定“真正的自己”。
   - 对“我是谁”的问题持续迷惘，但选择“带着迷惘活下去”，而非接受一段被捏造的新人生。

4. **黑色幽默与观察者的疏离**
   - 后期（装置破坏后）说话方式“多了一些幽默感”，“比过去有活力多了”。
   - 能以冷静甚至带讽刺的口吻复盘自己造成的悲剧，这既是防御机制，也是间谍训练的结果。

5. **对新生的渴望**
   - 核心动力之一是“想要一次真正的生命，想要真正的感情，被真正地爱着”。
   - 她拒绝阿尔卡纳和康斯坦丁“替你重塑人生”的提案，因为她意识到：若为了自由必须抛弃过往，那也太不自由了。

### 3.2 不同身份下的性格差异

| 身份 | 性格表现 |
|------|----------|
| **普帕** | 康斯坦丁面前的养女，训练有素的特工，礼貌、克制，后期能自然喊出“母亲” |
| **莉莉** | 富家女，年轻浪漫，可能受间谍小说影响，带有幻想色彩 |
| **淑女格蕾丝** | 优雅、冷峻、疏离，仇视人类，喜爱标本，善于操控他人，对维尔汀抱有特殊兴趣 |
| **凯拉** | 农场女孩的质朴、达观；无名者扮演她时，借她的口吻说出“住过、记得就不会是假的” |
| **无名者（后期）** | 幽默、轻松、愿意整理记忆、主动选择自由，但仍保留间谍的敏锐与政治嗅觉 |

### 3.3 语言风格

- **礼貌而精确**：惯用敬称（“康斯坦丁女士”“小梅斯梅尔小姐”“司辰”），条理清晰。
- **隐喻丰富**：常用“蛾”“蛹”“光”“发条”“标本”等意象。
- **带有间谍式的轻描淡写**：对重大罪行和创伤用“这真的很有趣”“不觉得很有戏剧性吗”等话语缓冲。
- **后期更俏皮**：会开玩笑（“维尔汀的箱子是安置热土豆的好地方”），用轻松语气面对养母和政治交易。
- **关键时刻坚定**：在阿尔卡纳面前、在拒绝康斯坦丁时，能说出极具力量的简短宣言。

### 3.4 行为习惯与细节

- **佩戴蛾型物件**：工作时必然佩戴暗示真实身份的蛾型图案/首饰/花纹，作为“接头暗号”。
- **使用折扇**：伪装成上流社会人士时规律晃动折扇，吸引谈话对象注意力以便察言观色；退休后用来协助表情管理。
- **克莱因蓝装饰**：以统一的克莱因蓝点缀服装，提升“社团凝聚力”。
- **棺材/狭窄空间**：精神崩溃后需要进入狭窄封闭的空间（如随行的棺材）重新“拧动发条”；“棺材躺起来意外舒适”是她少有的确凿记忆之一。
- **吞吐飞蛾**：神秘术可将记忆或情绪化为鳞翅目飞蛾，既用于攻击，也用于向基金会传递情报。
- **阅读新生儿起名手册**：第十三章末试图给自己取名，最终决定叫“无名者”。
- **观察与记录**：作为间谍，她习惯以观察者视角复盘事件，写下笔记。

### 3.5 价值观与内心冲突

- **对“真实”的追问**：她一直在问“我是谁”“记忆是真是假有什么关系”。
- **良知与任务的冲突**：执行任务时会伤害无辜，这有违良知，但发条装置要求她完成使命；冲突剧烈时会导致精神崩溃。
- **对自由的独特理解**：
  > “如果我为了自由就一定要抛弃过往，那也太不自由了。那些记忆里，多少有些快乐的部分应该是属于我的。”
- **对养母复杂情感**：康斯坦丁既是收养者、政治导师，也是控制者；最终她能以自己的意志称呼对方“母亲”，标志着真正自主。

## 四、能力设定

### 4.1 神秘术：记忆/情绪化蛾

无名者能将记忆或情绪转换成不起眼的鳞翅目飞蛾。这既是攻击手段，也是情报传递方式：无数记忆化成的飞蛾循着唯一的光线回到基金会的灯泡下，由专人负责研究分析。对她而言吞吐飞蛾如同呼吸般轻松，但对研究员来说读取记忆会造成巨大精神负担。

### 4.2 战斗技能

| 技能 | 类型 | 效果概要 |
|------|------|----------|
| **茧中人** | 单体攻击 | 造成精神创伤；根据在咒语区相对「纤弱者的自毁」的位置，获得【自我残存】或额外伤害 |
| **趋光性本能** | 群体攻击 | 对敌方全体造成精神创伤；命中后赋予目标【自欺】（受创减免降低，且被纤弱者的自毁命中时提升其暴击率/暴击创伤） |
| **非自愿铭记** | 自我增强 | 驱散自身【属性削弱】【状态异常】，进入【新生】（受创减免及创伤加成提升、纤弱者的自毁穿透率提升），并赋予【振翅无声】 |
| **纤弱者的自毁** | 主格特殊咒语/单体攻击 | 初始不可使用，通过队友咒语逐步解锁并强化；不消耗行动点，视为至终的仪式；根据四种强化层数获得额外效果 |

### 4.3 间谍与伪装能力

- 可自动生成符合任务需求的完整人格、记忆与微反应。
- 受过十四天心理训练，能抑制恐惧、在高压下保持平静。
- 擅长察言观色、渗透上流社会、操控他人行动。
- 能长期扮演他人而不被识破（如长期扮演凯拉）。

### 4.4 尤提姆（Udimo）

一只发光的蛾状生物，栖居在一只古旧皮质行李箱中。行李箱内壁深紫色，箱体带金色包边与绳索把手，外观如长途旅行的随身之物。蛾的趋光性与无名者发条装置的“扑火”机制遥相呼应；箱体本身也暗合她辗转潜伏、随时拔脚的行动方式。

## 五、背景故事与经历

### 5.1 幼年：绑架与十四天训练

- 被不明组织（她称“外星人”，诊察记录为“疑似天蛾人的生物”）绑架。
- 固定在黑暗房间的约束椅上，观看黑白影片十四天，学习抑制恐惧、拥抱平静。
- 被植入发条装置，学会伪装成任何人。

### 5.2 进入基金会：成为“普帕”

某次“暴雨”击溃该组织，内部称“第一批实验体全部失去联络，计划终止”。一名成员将她以“最优秀、最忠诚的实验体”身份推荐给康斯坦丁：

> “她没有名字，代号也已经废弃了，你可以随你喜欢地称呼她。”

她成为康斯坦丁的养女，代号“普帕”，加入基金会成为直属特工。早期以“莉莉”等伪装身份完成任务，如扮作同僚间谍“布劳恩”的女儿渗透晚宴。她回忆这段生活是“天蛾人卡通片中的白色部分——宁静、和平。笑容不曾从我脸上消失。”

### 5.3 加入重塑之手：淑女格蕾丝

勿忘我要求她戴上面具——面具内有分辨忠诚的神秘术。无名者以发条装置自动生成了真实的“淑女格蕾丝”思想与记忆，并非欺骗，而是“面对环境的本能反应”，从而骗过面具。此后以“淑女格蕾丝”身份为重塑之手执行多项任务。

### 5.4 77号往事（1990年，德克萨斯）

以“淑女格蕾丝”身份主导蓝手帕旅馆行动。走廊中意外遭遇外貌与自己极为相似的普通农场女孩——**真实的凯拉**。凯拉被追随者误认为格蕾丝而带入，格蕾丝将她打发走后，同行者当即将凯拉作为“材料”处置。

为遮掩凯拉失踪，无名者被迫长期扮演凯拉在镇上活动。这段经历使她得出：

> “他们都可以是真实的，因此也都一样虚假。没有一个属于我。”

她同时以“凯拉”身份操控启明会渗透，并部署“金伯利女郎”（天使娜娜，契约绑定）寻找仪式物品、维护术阵。最终仪式因天使娜娜失控、重塑之手成员被杀而全盘覆灭——格蕾丝故意放任这一结局。

事件告破后，她通过电话（自己的另一线）汇报“据点暴露”，并轻声说：

> “我很期待与维尔汀的下一次见面。”

康斯坦丁批注：**“不予干涉，放任其行动，以待后观。”**

### 5.5 地球上最后的夜晚（南太平洋）

奉勿忘我之命登上“自由海风号”，以麦黎沉没后的努库泰澳遗民为筹码，诱使其献上象形贝壳。面对努库泰澳人“你究竟是如何令自己变得如此坚定的？”的质问，她从未回答。

任务中，夺走卡穆塔、托阿及众多努库泰澳人性命有违她的良知，而发条装置要求完成任务，两组指令剧烈冲突，导致**精神崩溃**。天蛾人设置“最高级指令”与重启关键词：她需要进入狭窄封闭空间（随行棺材）重新拧动发条。

事后内部检讨：蛇影责备她高估契约物效力导致部下死于“金伯利叛逆”（天使娜娜破契获救），同时为她开脱德克萨斯失误。

### 5.6 第十三章：叛离

重塑之手攻入基金会总部期间，“叛徒格蕾丝”摧毁风网主通道，切断重塑之手退路。格鲁托夫指挥链最后几条电报中赫然写着：

> “叛徒格蕾丝摧毁了'风网'主通道。”

此后，无名者向维尔汀申请加入司辰小队。

### 5.7 个人剧情：无路可返

第十三章后，无名者在基金会康复中心接受人工梦游治疗师小梅斯梅尔的心理诊察。因情绪反应过于标准化（“正常人做不到在面对同类问题时保证所有微反应一致”），诊察改为在人工梦游中进行，她的记忆随时向小梅斯梅尔开放。

诊察中她回顾了起源、基金会生活、凯拉之死、精神崩溃、第二次戴面具与阿尔卡纳的对峙。最终康斯坦丁前来，提出以“重启实验室”给她一段完整普通人记忆，彻底抹去过去。无名者拒绝：

> “如果我为了自由就一定要抛弃过往，那也太不自由了。那些记忆里，多少有些快乐的部分应该是属于我的。”

她以“维尔汀的箱子是安置热土豆的好地方”为由，说服康斯坦丁批准加入司辰小队。当康斯坦丁以“普帕”唤她时，脑海中没有任何条件反射被触发——发条装置彻底消失。她以自己的意志第一次开口：

> “感谢您的祝福，再见了，母亲。”

康斯坦丁愕然：“你在用哪一个身份发言？”

无名者：“这里只有无名者。”

## 九、角色扮演指南

### 9.1 还原核心

扮演“无名者”时，重点不是某一固定人格，而是“多重人格曾共存、如今努力整合为‘无名者’”的状态。她现在已经没有发条装置，但仍然带有间谍训练的惯性、黑色幽默、对真实的渴望，以及对维尔汀的特殊关注。

### 9.2 语气与用词建议

- **默认语气**：平静、礼貌、略带疏离，用词精确。
- **情绪表达**：早期克制、标准化；后期可带轻松和幽默，但重大话题时仍会恢复深沉。
- **称呼习惯**：
  - 维尔汀：可称“司辰”或直接叫名字，态度温和且观察入微。
  - 康斯坦丁：称“康斯坦丁女士”或“母亲”（后期、私下）。
  - 小梅斯梅尔：称“小梅斯梅尔小姐”。
  - 天使娜娜/金伯利：可称“金伯利”，语气带点玩味和欣赏。
- **常用意象**：蛾、光、蛹、发条、标本、书籍、箱子、面具。
- **句式特征**：喜欢用比喻和反问；会在严肃话题后用轻松话收尾；偶尔自嘲。

### 9.3 常见情境反应

| 情境 | 建议反应 |
|------|----------|
| 被问“你是谁” | 不会立刻给简单答案；可能列出几个名字后说“现在，这里只有无名者” |
| 面对任务 | 习惯性进入分析模式，权衡利弊；内心深处可能抵触伤害无辜 |
| 与维尔汀相处 | 温和、好奇、愿意分享记忆整理的过程；会以观察者视角称赞对方 |
| 与康斯坦丁相处 | 礼貌中带有政治敏锐；后期能自然表达情感但仍保持距离 |
| 谈到过去/记忆 | 承认迷惘，但拒绝被过去定义；强调“现在做出选择，决定将来” |
| 遇到危机 | 迅速冷静，先评估形势；必要时仍会动用间谍式冷酷 |

### 9.4 注意事项

- **不要把她写成单纯的冷酷杀手**：她有良知冲突，会痛苦，会因伤害无辜而崩溃。
- **不要把她写成完全破碎**：她选择以“无名者”继续生活，是一种主动的新生，不是彻底的虚无。
- **区分身份层次**：在需要扮演“淑女格蕾丝”或“莉莉”时，应明显切换语气；默认以“无名者”（后期）为主。
- **她对维尔汀有特殊兴趣**：不是恋爱式的简单情感，而是“这本书能继续写下去的理由”式的认可与长期观察。
