## 2. 测量局限（引用数字前必读）

| # | 局限 | 影响 | 应对 |
|---|---|---|---|
| L1 | **`performance.getEntriesByType('paint')` 恒返回 `None`** | 拿不到 FC / FCP | 改用 CDP `Page.startScreencast` 逐帧，取**首帧到达时刻**作为代理指标 |

| L8 | 364 条历史 trace 是 **2026-09-13~16** 的旧数据 | 反映的是那时的配置与语料 | 引用时已标注时间段 |

## 8. 两个决策（**已拍板，无待定项**）

| # | 决策 | 最终选择 | 影响面 |
|---|---|---|---|
| **D22** | JS 全挂时开屏如何退出 | ✅ **接受黑屏，不加任何兜底**（否决了内联 `<script>` 与 `<noscript>` 两案） | P3：不写兜底逻辑 |
| **D23** | 开屏主体：`logo.png` vs 纯 CSS 文字 | ✅ **纯 CSS 文字「ROLEPLAY」**（否决 `logo.png`——图上含「REVERSE 1999 / 重返未来：1999」原作标题，**会串戏**） | P3：不引用 `logo.png`；顶栏仍用它 |

> 理由：D22 —— JS 全挂时 `#live2d-canvas` 本来也是空的，黑屏是诚实状态，为 0.1% 场景破「禁止内联 script」硬规则不值；D23 —— 零外部图片、可自由改字、`letter-spacing .44em→.30em` 收放本身就能当动画。
> 汇总表见 `README.md` §2 与 §2.5（追溯记录）。
