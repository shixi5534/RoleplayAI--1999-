## 5. 多页的代价与对策（D08）

### 5.1 代价实测

| 路径 | 代价 |
|---|---|
| index → settings | ≈ 250ms（无模型） |
| **settings → index** | **6.8~9.3 s**（重载 Live2D 模型） |

### 5.2 对策：开屏自动盖住（零额外逻辑）

因为开屏退场绑的是 `live2d:init-done` 事件（见 `01-开屏动画.md` §1），而该事件在每次 `index.html` 加载时都会派发 ⇒ **开屏天然覆盖整个重载期，不需要任何"返回时特殊处理"**。

这正是 D06（每次进入都播）+ D08（接受重载）两条决策的组合价值。

### 5.3 不做 SPA / 不做 Turbo / 不做 prefetch

| ❌ | 理由 |
|---|---|
| SPA 路由 | 与"真多页"决策矛盾；且要把 16 个 script（含 4 个 UMD）改成动态加载，改动面巨大 |
| View Transitions API | 跨文档跳转支持度不足，且无法解决"模型重载"这个真瓶颈 |
| prefetch `settings.html` | 收益 250ms，成本是每次进主页多一个请求 |

### 5.4 URL 必须带扩展名（实测坑）

`src/roleplay/main.py:189`：

```python
app.mount("/", StaticFiles(directory=str(frontend_dir), html=True), name="frontend")
```

`html=True` **只对目录 index 生效**。所以：

| URL | 结果 |
|---|---|
| `/settings.html` | ✅ 200 |
| `/settings` | ❌ **404** |
| `/knowledge.html` | ✅ 200 |
| `/knowledge` | ❌ 404 |

⇒ **所有链接必须写 `.html`**。若想支持无扩展名，需在 `src/roleplay/main.py` 加路由（不改更省事）。

## 7. `?v=` 版本号维护

### 7.1 现状真相

`src/roleplay/main.py:48-71` 的 `NoCacheMiddleware`：

```python
_NO_CACHE_SUFFIXES = (".html", ".js", ".css", ".json", ".map")
_NO_CACHE_PREFIXES = ("/assets/", "/js/")
# 命中就写 Cache-Control: no-store, max-age=0，并删 etag/last-modified
```

⇒ **`?v=` 在服务端强制 `no-store` 下其实无缓存收益**。它唯一的实际作用是**防用户浏览器里旧的 Service Worker / 中间代理**，以及"让人知道改过"。

### 7.2 多页方案下的规则

| 规则 | 说明 |
|---|---|
| 同一文件在多页被引用时，**版本号必须一致** | 否则同一份 JS 会被当两个资源 |
| 改文件 → **所有引用处同步升** | 现在 15 个 script 在 `index.html:294-316`，P4 后要复制到 3 个页面 |
| 不引入构建工具自动注入 | 评审已定"不上打包器"；手改 + P1a 的 lint 检查就够 |
| 建议：P1a 加一条 lint 规则 | 检查同一 `src` 在多文件里的 `?v=` 是否一致 |

### 7.3 现有版本号快照（P4 搬迁基准）

`frontend/index.html:294-316`：
`live2dcubismcore.min.js?v=7` / `pixi.min.js?v=7` / `pixi-live2d-display-cubism4.min.js?v=7` / `rain.js?v=1` / `canvas-fx.js?v=6` / `live2d.js?v=12` / `voice.js?v=7` / `llm-switch.js?v=3` / `live2d-bootstrap.js?v=8` / `pet-core.js?v=1` / `pet-voice.js?v=6` / `pet-subtitle.js?v=5` / `chat.js?v=11` / `knowledge.js?v=1` / `desktop-pet.js?v=4` / `layout.js?v=1`

## 10. 明确不做

| ❌ | 理由 |
|---|---|
| SPA / 客户端路由 | 与"真多页"决策冲突（D05） |

| 现在就做 `src/core|data|features|ui|pages` 大重构 | 评审实测 18.8~27.3 人日，与四条需求的视觉收益无关 |
| 动 `docs/` 里 `redesign.html` | 评审 §2.2：移出 `frontend/` 后**打不开**（`main.py:187-189` 只挂 `frontend/`）。建议留 `frontend/` 改名 `_design-archive.html` |
