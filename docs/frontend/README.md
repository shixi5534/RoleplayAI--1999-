## 0. 一句话

把当前"16 个 `<script>` 平铺 + 全局对象互摸 + 两套 CSS 变量表"的前端，改造成**一个以角色为唯一主角的舞台**：进场有开屏、对话在角色旁浮现、装饰围绕角色、设置全部退到别的页面；同时给 RAG 检索加一套能事后分析的日志。

## 5. 一页纸的硬约束（实现时不要踩）

1. **`frontend/assets/lib/` 4 个库全是 UMD**，当 ESM 加载得到空命名空间。⇒ 3 个经典 `<script>` 阻塞排在 module 前，**不用 importmap**（评审 §1.1 已否决）。
2. **`ctx.filter = "blur(...)"` 永久封杀**：1920×1080 下单次 149.6 ms/帧，`canvas-fx.js:52` 注释记着"实测压到 0.4fps"。
3. **`connect-src 'self'` 不动之外，CSP 别的一律不改**；不提前加 `wasm-unsafe-eval`。
4. **`?v=` 版本号在服务端 `no-store` 下其实无缓存收益**（`main.py:48-71`），但多页方案里仍要同步升，避免混乱。
5. **`_clampOffset()` 现在什么都不做**（`live2d.js:532-540`，注释明说"按用户要求放开边界"）——所以"本体放左边"只需给 `model_offset.x` 一个默认负值，**不改 `_fit`**。
6. **`.stage` 有 `overflow: hidden`**（`index.css:318`）⇒ 舞台内粒子贴边会被裁掉而不是"溶入"，必须在距边 <8% 时强制提前溶掉。
7. **不做动态舞台宽**：`setZoom` 会连带调 `_fit`（`live2d.js:1271-1274`），逐帧调用 = 每帧全量重排，且与 `layout.js` 的 `roleplay_layout_split` 持久化打架。
8. **不引入任何 3D 依赖**：Blender 只走"渲装饰视频/出设计稿"两条零依赖路径，**不引 three.js**。判断门槛：Live2D 冷启从 7s 降到 2s 以内再谈。
9. **装饰层插槽已存在**：`index.html:12-16` 的 4 个 `aria-hidden="true"` 全屏 div（`.kv-backdrop`/`.kv-veil`/`.film-grain`/`.rain`，z `-2/-1`）。未来加第 5 个 `.fx-cinema` 即可，零 JS 改动。
10. **`_measureContent()` 是角色占位的唯一权威**（`live2d.js:443-518`，返回 `{x,y,w,h,measured}`）。换任何渲染器只要还能给这个盒子，`_fit`/拖拽/吸附全可复用。
