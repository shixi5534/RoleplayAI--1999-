## 二、叠加的增益递减（诚实记录）

- 单独相加预期 +25 / +26，实测 **+20 / +23** → **重叠 5 题 / 3 题**；
- 说明两个改动在部分题上救的是同一批（都指向"中文问法缺英文实体名"这一类）；
- 但叠加仍是**净正**（+20/+23 优于任一单独档），故推荐同时开启。

**互补性的证据**：A 档（实体扩展）使 multi-hop 从 51.7% → **57%**；
C 档在此基础上注入再 +5 题——说明双路融合补到了实体级扩展覆盖不到的句子级匹配。

## 四、效果来源拆解（为什么这两个有效而其它无效）

| 手段 | 结果 | 原因 |
|---|---|---|
| **实体扩展**（中文 query + 英文实体名） | **+18/+18** | 把"描述性中文问法"锚到**英配角色名**上 → 图路激活 + 语义命中 |
| **中英双路融合**（中文路 + 英文路） | +7/+8 | 中文路命中中文正典（拼写准）、英文路命中英配转写（覆盖广），互补 |
| 纯英文替换 query | −22/−15 | 丢掉中文正典路；英文块是 ASR，专名拼写不可靠 |
| 同义改写 / 整体重排 / CE 精排 / PPR 加权 / 摘要节点 | 0~负 | 均属"往已有信号上重复加权"，不带来新信息 |

**共同规律（今天三次独立验证）**：有效改动都必须**引入语料里没有的新信息**
（外部作品知识 / 另一种语言的查询视角）；只做排序与加权调整的一律无效。
