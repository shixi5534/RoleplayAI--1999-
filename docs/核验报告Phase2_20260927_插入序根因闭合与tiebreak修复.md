## 1. 决定性实验设计（判据先于结果）

**问题**：R4 声称的 +4 题收益是真收益，还是测量假象？

**假设 H**：`retriever.py:300` 的 `sorted(alias_index.keys(), key=len, reverse=True)`
是稳定排序，同长键先后由 **dict 插入序**决定；暖进程（Applier 落盘后内存态）
与冷启动（自 graph.json 重建）插入序不同 → 边界题翻转。

**判据（预先固化）**：
- H 成立 ⟺ 用「两种合法但顺序不同的」实体遍历序构造 alias_index，能观测到
  `link()` 输出差异，且差异集中在 R4 声称的题目上；
- 修复有效性 ⟺ 加显式次级键后，两种插入序给出**完全一致**的结果。

**工具**：`scripts/_r5_tiebreak_experiment.py`（只读，不写图/索引）。

## 2. 实验观测

| 检验项 | 结果 |
|---|---|
| alias_index 键总数 | 7946 |
| **长度与至少一个其它键相同的键数** | **7945 / 7946**（几乎全体处于 tie 组内） |
| 最大歧义长度组 | len4→1738 键、len3→1674、len2→1414、len5→1291、len6→742 |
| 被多实体声明的别名串 | 3 例（`法案`、`许可证`、`飞行巫师`）→ `setdefault` 使**归属**也依赖顺序 |
| 两种插入序下「无次级键」排序结果相同 | **False** |
| **两种插入序下 `link()` seeds 不同的题数** | **37 / 300** |
| 加显式次级键后两序一致 | **True（300 / 300）** |

> 这证实了交接文档的怀疑，且**量级更大**：不是"3 道边界题受扰动"，
> 而是整个别名解析链排序在暖/冷之间全局不稳定（7945/7946 键在 tie 组内），
> 只因绝大多数键最终仍归到同一实体，故仅 3 题翻转 hit@6。

## 3. 修复内容（commit `6e49d8a`）

1. `retriever.py:300` → `key=lambda k: (-len(k), k)`（长名优先语义不变，去除插入序依赖）。
2. `graph_store.from_dict` → 两遍构造：先登记全部规范名（规范名优先），
   别名冲突按「实体 name 等于该别名者优先，其余取 eid 字典序最小」裁决，键按排序插入。
3. `graph_store.save` → 统一 `indent=2 + CRLF`，与冻结件逐字节对齐
   （此前 save() 产出压缩+LF，与冻结的 `c021f0a0bc7a0dce` 不符，且产生 43 万行伪 diff）。
