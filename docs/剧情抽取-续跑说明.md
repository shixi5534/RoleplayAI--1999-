## 三、抽取必须守的硬约束

**概念类型占比 ≤15%**（>20% `--apply` 会打 `[warn]`）。
只留设定专有具名术语或核心世界机制（暴雨、暴雨综合征、灵魂数、Gnosis、Phenomenal World、
Numa、巫术、术阵、普纽玛、地脉）。不要抽 `truth`/`ritual`/`research`/`数学`/`休息` 这类普通名词。
> 该指标按「块内出现次数」统计，同一概念在多块重复会推高占比。裁剪办法：概念只在其核心讨论块保留。

**`is_noise_entity` 的 5 类误杀**（写入 name 会命中，放进 `aliases` 则不会）：

| # | 规则 | 触发例 |
|---|---|---|
| 1 | `len(n) < 2` | `雾`/`岛`/`塔`/`Z` |
| 2 | 含句点 | `T.Kettler`、`Cavendish Jr.` |
| 3 | `^the\s+` | `the Sixes`、`The Committee` |
| 4 | `len(core.split()) >= 4` | `Ford sextant Model T`、`Flying Carpet Travel Agency` |
| 5 | 与常用词同形 | `mine`（被当事物代词） |

**统一规避手法**：name 压短或加限定词，完整形式塞进 `aliases`。

**归属存疑的名字不要并进任何既有角色的 aliases**，单独立实体留待核查。
（`Winsong` 就是典型：三个 worker 给出三种互斥判断——地脉研究者 / 无名者变体 / Vila，

## 四、子代理限流（重要运维事实）

**两次触发账号级 429 限流**：
- 第一次：并发 **7 个** worker → 重置点 23:27，过点后仍连续 7 次失败
- 第二次：并发 **2~3 个** worker → 重置点推到 **09-12 04:29**，worker 跑 6.5 分钟后失败
- 第三次（04:29 之后）：并发 **3 个** worker → 重置点推到 **09-12 18:27**，
  两个 worker 均在写出 jsonl **之前**失败（无可抢救产物）
- **结论：该限流是账号级滚动窗口，并发越高、推进越多，重置点越往后推。**
  唯一安全的节奏：**单轮 1 个 worker**，且每批之间间隔 10 分钟以上

**建议：单轮只放 1 个 worker，每批间隔 ≥10 分钟。** 宁可慢，别再触发。
