# 核验报告（Phase 5 附带发现）：R4 重放链路曾被仲裁编辑切断 — 2026-09-27 晚

> 结论先行：**R4 提案的 R4-K01 在第二会话被改成 `remove_alias` 但缺 `alias` 字段，
> 导致 Applier 全图 fail-closed，R4 从 `prev.r4` 完全无法重放（rc=1）。**
> 该条实际**从未落盘**（图里 `诊疗@诊所` 仍在），且别名总数只减 77 而提案声称 78。
> 已还原为 `keep_with_note` 并补录「仲裁未落盘」如实说明；现在可从 `prev.r4`
> **逐字节复现冻结 SHA `c021f0a0bc7a0dce`**。

## 1. 发现路径

Phase 3 修复 Applier 落盘格式（indent=2 + CRLF）后，做回归验证：
用 `--graph <副本>` 在 `backups/graph.json.prev.r4` 上干跑 R4 提案，预期全绿。
实际得到 **rc=1**：

```
条目: 78 | 预检错误: 1 | 警告: 0 | 后检错误: 0
  [预检] [R4-K01] alias 不在属主别名表: None@诊所
[FAIL] 校验未全绿，不写盘。
```

## 2. 根因

`R4-K01` 的 `target` 是**裸字符串** `"诊所"`，且**没有顶层 `alias` 字段**；
而 Applier 的 `_alias()`（`_graph_apply_repairs.py:35-39`）只在
`target` 是 dict 时取 `target.alias`，否则取 `entry["alias"]` → 返回 **None**。
`remove_alias` 分支随即报「alias 不在属主别名表: None@诊所」→ 全图**不写盘**。

第二会话把该条从 `keep_with_note` 改成 `remove_alias` 并追加了仲裁文本
（「采纳 Verifier remove 方案」），但**没有同时补 `alias` 字段**，于是：

- 该条既**没有生效**（fail-closed 使整批不写盘），
- 又把**整批 R4 的重放能力**切断了（从 prev.r4 起 rc=1）。

## 3. 三点独立证据表明「该仲裁未落盘」

| 证据 | 观测 |
|---|---|
| 图上别名仍在 | live `诊所.aliases = ['工坊', '诊疗']`，`alias_index['诊疗'] = 诊所`（与 `prev.r4` 完全相同） |
| 别名总数对不上 | `prev.r4` 994 → live **917**，即摘除 **77** 条；而提案含 **78** 条 `remove_alias` |
| 结构自检 | 78 条 `remove_alias` 中，**只有 R4-K01** 无法解析出 `(owner, alias)` |

## 4. 受控重放实验（`scripts/_check_r4_replay.py`）

在 `prev.r4` 的临时副本上分别重放：

| 变体 | rc | 结果 SHA16 |
|---|---|---|
| **A** 现状提案（K01 = remove_alias，无 alias 字段） | **1**（fail-closed，未写盘） | `eac19efec7fa9026`（= prev.r4 原值） |
| **B** K01 还原为 `keep_with_note` | **0** | **`c021f0a0bc7a0dce` = 冻结锚点 ✓** |

B 逐字节复现冻结值 → 证明 **R4 落盘时的实际语义就是 K01 = NOOP**，
也顺带证明 Phase 3 的落盘格式修复（indent=2 + CRLF）端到端正确
（否则重放结果不会等于冻结 SHA）。

## 5. 处置

- `R4-K01` 还原为 `keep_with_note`；保留原仲裁文本，并补三个字段：
  `arbitration_status = "NOT-APPLIED"`、`not_applied_note`（完整证据链）、
  `replay_verified`（复现锚点说明）。
- 修复后重放：A、B **双双 rc=0 且均得 `c021f0a0bc7a0dce`** → 重放链路恢复。
- `remove_alias` 条数回到 **77**，与图的 994→917 对账一致。

## 7. 方法学

- 回归验证**先于**宣布局部修复完成（Phase 3 改格式 → 立即在真实提案上重放）；
- 报错即追根因，不把它当作"预期失败"绕过；
- 三个独立通道（图上别名字段 / 别名总数 / 结构自检）交叉确认"未落盘"；
- 受控实验用 A/B 双变体分离"提案缺陷"与"重放能力"；
- 修文不改史：保留原仲裁文本，另加 `arbitration_status` 说明其未执行。
