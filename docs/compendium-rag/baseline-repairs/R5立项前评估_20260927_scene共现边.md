# R5 立项前评估报告（scene 共现边）— 2026-09-27 晚

> **结论先行：R5 按其原始设计（同 chunk 共现补「同场」边）收益极小（+1 题 / 196），
> 且以 PPR 全局稀释为代价。建议：不作为独立修复批次落盘，改为「独立 RRF 通道 + 仅补结构化缺口题」，
> 或先立 R6/查询侧供给。本报告给出全部实测数据与判据。**

## 0. 为什么先评估而不是直接落盘

R5 由相遇测试催生（`docs/compendium-rag/ranking/排序侧实验_执行报告_20260926.md` §304）：
「2 跳全可遇仅 12.5%、**同场相遇=0**、1243 条边无版本标注」。
作战书 §4bis 与 `BASELINE_v4` 均把 R5 列为 P1，且**明确把 PPR 稀释列为闸门重点**。
按预注册纪律（判据先于结果），落盘前必须先量清规模与稀释。

## 1. 规模测量（`scripts/_r5_scope_measure.py`）

- 角色实体 **2023 / 7033**；有角色出现的 chunk **3589**；≥2 角色的 chunk **3452**（R5 候选）
- 每 chunk 角色数分布：2→365、3→709、4→718、5→652、6→426、7→272、8→148（长尾）

| 方案 | 边增量 | 相对现有 29,957 边 |
|---|---|---|
| A 全连接（两两） | +36,898 | **+123%** |
| B 星型（度数最高为锚） | +12,788 | +43% |
| C 全连接 + 每 chunk 上限 K=6 | +28,440 | +95% |
| C 全连接 + 上限 K=4 | +16,760 | +56% |

**稀释预判**：维尔汀度数 1524 → 5103（×3.3）、十四行诗 ×4.0、APPLe ×3.6。

## 2. 变体实测（`scripts/_r5_variant_scan.py`，196 answerable，graph_only 口径）

> **方法学校验**：本 harness 的 base 复现官方基线 **132/196 = 0.6735**，
> 与正式 eval300 的 graph_only 逐位一致 → harness 可信。
> 为保证变体扫描可行，PPR 改为数学等价实现并加了记忆化（163s→47s / 40 题），
> 等价性由脚本内 `--verify` 断言（12 题逐题相同）。

| 变体 | 边增量 | hit@6 | vs base |
|---|---|---|---|
| **base** | 0 | **132/196 = 0.6735** | — |
| star | +12,788 (43%) | 133/196 = 0.6786 | up=1 (R009)，down=0 |
| chain | +12,788 (43%) | 132/196 = 0.6735 | up=0，down=0，**MRR ↓ 0.5328→0.5271** |
| cap:6 | +28,440 (95%) | 133/196 | up=1 (R009) |
| cap:4 | +16,760 (56%) | 133/196 | up=1 (R009) |
| full | +36,898 (123%) | 133/196 | up=1 (R009) |

**关键事实**：
1. **+43% 与 +123% 边数收益完全相同（都只有 R009 一题）** → 收益与规模无关，指向"结构性只差一题"。
2. **chain 变体 MRR 下降**（0.5328→0.5271）且零收益 —— PPR 稀释的直接影响。
3. 六变体中五个只救 R009，说明同场结构对现有 gold 块的可达性帮助极小。

## 3. 稀释机理量化（`scripts/_r5_dilution_quantify.py`）

PPR 转移为 `damping × s × (w / wsum)`，`wsum` = 节点全部出边权重和。
注入同场边后（star，+12,788 边）：

| 枢纽 | wsum | 既有边平均摊薄 | 度 |
|---|---|---|---|
| **维尔汀** | 1516 → 2769 | **×0.548** | 1524 → 5103 |
| 十四行诗 | 568 → 749 | ×0.759 | 572 → 1087 |
| 玛蒂尔达 | 487 → 645 | ×0.754 | 491 → 944 |
| 星锑 | 522 → 664 | ×0.786 | 529 → 934 |
| 圣洛夫基金会 | 504 → 504 | ×1.000 | 511 → 511（无角色共现，未受影响） |

**维尔汀的 363 个既有邻居，每一个的相对转移权重都被摊薄 ×0.548**（如 阿尔卡纳 0.00106→0.00058）。
即：同场边让 PPR 多走的每一跳，都以其原有邻域的激活为代价。
这就是"边数翻倍而收益不增"的机理。

## 4. 备选设计：独立 RRF 通道（`scripts/_r5_scene_channel_scan.py`）

不改图、零稀释：把"chunk 内与**本轮种子**共现 ≥2 个角色"作为独立通道参与 RRF。

| 权重 w | hit@6 | MRR | vs w=0 |
|---|---|---|---|
| 0（现通道） | 132/196 = 0.6735 | 0.5328 | — |
| 0.5 | 132/196 | 0.5358 | up=0 down=0 |
| 1.0 | 132/196 | 0.5362 | up=0 down=0 |
| 2.0 | 133/196 = 0.6786 | 0.5375 | up=1 (R238) |
| 3.0 | 133/196 | 0.5375 | up=0 down=0 |
| 5.0 | 133/196 | 0.5401 | up=0 down=0 |
| 8.0 | 133/196 | 0.5401 | up=0 down=0 |

- 通道法**确实避开了稀释**：MRR 单调**上升并饱和**（0.5328→0.5401），全程无任何 down 题。
- 但 hit 在 w=2 就**达到平台**，w 再增大 4 倍（2→8）也**再无增益**（恒 133/196）。
- **平台行为是"结构性只差一题"的强证据**：不是权重没调够，而是同场证据对现有 gold 块召回
  并无更多可兑现的空间；继续加权只提升既有命中题的排名（MRR），不新增命中。
- 且它救的是 **R238**，与边注入法救的 R009 不同 —— 两个设计各自只触达一题，互不重叠。

## 5. 判据与建议

**判据（预先固化）**：R5 值得作为独立修复批次落盘 ⟺ 增益显著（≥ +3 题）且无回归。
实测**未达**：两种设计均 +1 题（边注入救 R009、通道法救 R238，互不重叠），
边注入法还有稀释与 MRR 下降风险；通道法虽零稀释但 hit 在 w=2 即饱和（见 §4 平台证据）。

**对"同场相遇=0"的正确解读**：相遇测试衡量的是**实体↔实体多跳可达性**，
而 eval300 的 hit@6 衡量**问题→gold 块**召回。同场边对前者有结构意义，
对后者帮助有限 —— 因为现有三通道（尤其 mention 通道直接返回种子实体的出现块）
已覆盖了大多数同场证据。**两者不是同一个指标，不可混同。**

**建议（三选一，待用户裁决）**：
- **(甲) 不落盘 R5 的边注入方案**；把「同场」以**独立 RRF 通道**落地（零稀释、MRR 正向、可回滚），
  权重取 1.0–2.0，并如实标注 hit 增益 +1（不显著）。
- **(乙) 先做 R6（版本标注使用 + 时间一致性审计常态化）+ P3 查询侧供给**，
  R5 挂后评估；理由：R5 的结构价值（相遇测试）不依赖 eval300 增益。
- **(丙) 定向补：只对相遇测试暴露的具体缺口对（如玛尔塔薄邻域、探针组）补少量同场边**，
  而非全量注入 —— 用最小边增量换结构收益，彻底规避稀释。

**无论选哪个，都不应把 R5 的 +1 题写成"收益"** —— 它是噪声量级（300 题集上 1 题 ≈ 0.5%）。

## 6. 复核方法学

- 判据先于结果（本文 §5 判据在跑变体前固定）；
- harness 先用已知基线（132/196）自证，再用于变体比较；
- 快慢 PPR 逐题等价断言，防止"优化引入行为改变"；
- 稀释不只报结论，给出 wsum 与邻居相对权重的**直接数值证据**；
- 涨跌同表 + 逐题题号；PPR 缓存跨变体显式清空（防 id(adj) 复用污染）。
