#### P2 前置诊断（2026-10-08，只读，`scripts/compendium_rag_p2_landing_diag.py`）

**本节推翻本节前提。** 原表把孤立率 0.1594 的根因写成「1089/7033 实体名不落地」，实测不成立：

| 读数 | 值 |
| --- | --- |
| 孤点总数（v9-a） | 1128（0.160387） |
| 孤点中「名字逐字在语料里」 | **1086（96.28%）** |
| 孤点中「名字不落地」 | 42（3.72%） |
| 全图名字不落地 | 965（与 CHRONICLE 2026-09-26 的 967 同量级，口径可复现） |
| 不落地但**连通**的实体 | 923（965 − 42）——它们是关系端点，删了就是毁边，不是清理 |

结论：把孤立率押在「别名落地」上，天花板是 42/1128 = 3.7%。别名落地真正能治的是**精确率与 name-key 死键通道**（923 个连通死键），不是连通性。两条线必须分开，否则会拿 P2 的预算去买 P2 治不了的东西。
