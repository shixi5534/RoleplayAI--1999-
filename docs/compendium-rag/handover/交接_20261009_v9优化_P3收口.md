## 7. 操作手册（这台机器上踩过的坑）

```bash
# 一切 python 走 venv + utf8
PYTHONPATH=src .venv/Scripts/python.exe -X utf8 <脚本>
# 冻结口径（跑任何读数前都设齐）
CMPRAG_LEX_WEIGHT=1.0 CMPRAG_RRF_K=1 CMPRAG_LEX_FIRST=0 PYTHONHASHSEED=0
```
- **长任务必须脱离会话生命周期**：`powershell Start-Process -WindowStyle Hidden bash -ArgumentList ...`；**别用后台 Bash 跑几十分钟**（会被会话回收）。
- **Windows 可观测性**（[[reference-windows-python-job-observability]]）：`stdout` 是块缓冲的，**别拿日志判断进程死活**，去看 `*.jsonl` 产物在不在长；判卡死看**子 PID 的 CPU**，不是父进程。
  本次实例：`Get-CimInstance Win32_Process -Filter "Name='python.exe'"` 看到**两个同名进程不是竞态**——4448 是 venv 桩（CPU 0.015s），30672 是真身（CPU 3110s 一路在烧）；再用「逐文件查 qid 重复」佐证（7 个文件 0 重复）。
- **全量成本参考**：影子评测 3130 个「题×档」= **10:07→11:57（110 分钟）**，单题档 ~1.34s（冷档 1.84s）。P4/P7 要报三集全量就先按这个数量级排时间，别中途以为它卡了。
- 冒烟与全量**分目录分文件名**——续跑逻辑按 qid 去重，冒烟的 3 题会冒充全量。
- Bash 里**别写反斜杠转义的 Windows 路径**（`\r` 会被吃掉，`cd` 直接失败）；用 `C:/...` 正斜杠。
- 嵌套引号的 heredoc 会把 bash 解析搞崩；要跑一次性 python 就用 `.venv/Scripts/python.exe -X utf8 - <<'PY'` 单一 heredoc，**不要 `cmd || cmd2` 两段同形**。
