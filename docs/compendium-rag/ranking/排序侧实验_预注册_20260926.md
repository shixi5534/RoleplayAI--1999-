## 1. 预注册闸门

### C1 k=10 端到端实测（知识产出，无验收门槛）
- **前置锚点**：`--top-k 6` 重跑必须与 `eval_{300_cn,native}_after_welds.json` 在字段

### C2/C3/C5 离线重排（验收闸门）
- **硬门槛（任一违反 = 该配置否决）**：
  - unanswerable(104) hit@6 **不新增命中**（≤ 1/104 = 0.0096）；
  - grounded = **1.000**（重排只许重排既有 chunk_id，脚本须程序化断言）；
  - native(250) full hit@6 点估计 **不低于 0.6320**（holdout 纪律：策略只在 300_cn answerable 上拟合）；
  - 题集 i（C7）重排后 empty/strong hit@10 **不显著低于基线**：点估计降幅 ≤ 1pt 且 McNemar p > 0.05。
- **主门槛**：300_cn answerable(196) full hit@6 **≥ 0.8010**（不降）。
- **推荐门槛（全满足才进入"建议接线"结论）**：hit@6 净增益 **≥ +1.5pt（≥3 题净翻转）**，
  且 LOO-CV 过拟合差距 ≤ 1pt，且 holdout native 非负。CI 如实报（n=196 下 +2pt 的 CI 大概率含 0，不回避）。
- **盲特征纪律**：`eval_keywords` / gold 证据字段只许评测、**严禁入特征**（`_rank_rerank_lab.py` 已隔离并写明）；
  oracle 分析（用 gold 的可达上限）只作诊断，与盲策略分开栏报告，**不许把 oracle 数字当策略成绩引用**。
- **消融**：最优组合必须给逐特征 leave-one-out；增益必须可归因，归因不了的只报现象。

## A3. 主攻路径（按性价比排序）
1. **宽池盲重排**：采集 top-30（pool=120），盲策略把 top-30 压回 top-6。oracle 上限 fresh 实测后给出（旧宽窗名次推算 ≈ 0.93；hit@10 实测若 ≈0.86，则 oracle(30) 更高）。
2. **检索参数调优**（RRF 权重 / vector_top / max_edges / top_n / seed_threshold）：每个变体**单独预注册 + 单独采集 + 全部门**，不许合并解读。
3. **本地 LLM 查询改写**（Ollama 拉小模型，联网下载）：仅当 1/2 不足 85% 时启动，同样预注册。
4. **CE 重排**：本机已有 `models/bge-reranker-base-onnx`（零下载，先跑）；`bge-reranker-v2-m3` 作为联网增强（CPU 推理慢，只对边界候选 rank 5-10 打分）。
