### 2.2 v1 与 v2 的行为差异（一句话）

- **v1_tailcut（历史行为，冻结参考实现）**：`context()` 拼完头段+证据段后整体 `out[:max_chars]` **尾切** —— 最后一块会被从中间切断。

### 3.2 三条硬规则（`ANSWER_SYSTEM_PROMPT` 原文要点）

1. **只准引用带编号片段**：「每一条事实都必须用片段自己的编号标出来源，例如 `[S1]`、`[S2]`；编号必须与片段前缀 `[S1 chunk=… doc=… cat=…]` 里的编号逐字一致。不得引用不存在的编号，不得把多个片段的内容混成一条没有编号的陈述。」
2. **片段里没有的，一律答「未记载」**：「不得用先验知识、其他作品设定、网络资料或推测补全。如果片段不足以回答，就直接回答「未记载」，并说明还缺哪一类信息。」
3. **不得引入外部游戏知识**：「即使你确定某个设定、剧情或角色关系是正确的，只要片段里没有写，就不许出现在回答里；也不得引用其他作品或现实世界的资料。」

补充要求：用简体中文、先给结论、不复述提示词、不大段抄录；片段互相矛盾时如实指出并分别给编号，不替它们调和；「「未记载」是合格回答，不是失败；编造才是。」

**设计理由（`compose.py:1-23` docstring 原文要点）**：审查期 L3.4 域内幻觉率 0.1475 的共性是「把同正典其他片段的原句当成本条依据引用」，而模型对《重返未来：1999》带有大量**先验知识** —— 一旦允许自由陈述，「读到了」与「本来就知道」就再也分不开。故提示词把回答约束成**片段的函数**。

**装配顺序固定**（`compose.py:118` docstring）：① system（`ANSWER_SYSTEM_PROMPT`，有 role_card 时追加`【角色卡】`）→ ② history（空则整段不出现）→ ③ 末条 user = `"【检索片段】\n{ctx or CONTEXT_EMPTY_NOTICE}\n【问题】\n{query}"`。理由（docstring）：「证据离问题越近，模型越难『读着读着滑回先验知识』；同时保证『末条是 user』这一网关友好形态」。
