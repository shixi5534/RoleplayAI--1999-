```python
def fingerprint_of(corpus_fp: str, model: str, prompt_version: str,
                   chunk_chars: int, normalizer_version: str | None = None) -> str:
    parts = [SCHEMA_VERSION, corpus_fp, model, prompt_version, str(chunk_chars)]
    if normalizer_version is not None:
        parts.append(normalizer_version)
    for part in parts:
        h.update(part.encode("utf-8")); h.update(b"|")
    return h.hexdigest()[:16]
```

docstring 原文关键句：「`normalizer_version=None` reproduces the pre-n2 legacy hash byte-for-byte, so frozen graphs written before 归一化版本入指纹 still verify. Pass the real `NORMALIZER_VERSION` for anything built from now on: 归一化是本地后处理，改它不改语料/提示词，若不入指纹则「图变了但指纹没变」——审查期实测过这个盲区。」

**结论（两点，都有产物/源码支撑）**：
1. **v8 → V9P1 指纹变了**（`7dc29bf90681a3f7` → `14daf1bbfa407388`）：因为 V9P1 首次把 `NORMALIZER_VERSION` 纳入指纹，且 v8 落盘时该字段尚未入哈希（`normalizer` 字段为 `None`）。→ 这是**口径变更**，不是「图内容漂移」。

## §4 L4.5 装置与方法学教训

### 4.1 为什么要自建装置（而不是用 `audit_l4.py --prep`）

`scripts/audit_l4.py:788-792` 的采样逻辑（本人逐行读，原样）：

```python
cand = [cid for cid, s in per_chunk.items() if len(s) >= 3 and cid in text_by_cid]
rng = random.Random(SEED)
rng.shuffle(cand)   # 注释：随机抽样，不按角色数排序——否则抽到的全是"大会场"块
cand = sorted(cand)[:MULTISCENE_N]
```

- `SEED = 42`（`:36`）、`BATCH = 50`（`:37`）、`MULTISCENE_N`（`sorted(...)` 截断到 60）。
- **`shuffle` 之后紧跟 `sorted`，shuffle 被完全抵消** → 实际是「**chunk_id 字典序前 60**」，**不是随机抽样**。注释里写给自己的提醒（「不按角色数排序」）本身没错，但被接下来的 `sorted` 推翻。
- 而 r8 落盘后**候选池由 2793 降到 2792**（`p6_apply_r8.json` 的 `7_sample_pool_check` 记 `consistent=false`）→ **照原样重跑 `--prep` 会换出/换入块，两轮读数就失去可比性**。
- 这是自建「**冻结并集双臂装置**」的直接动机。
