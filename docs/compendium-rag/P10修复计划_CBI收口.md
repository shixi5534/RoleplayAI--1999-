## R7 把"答案层边界指令"当控制项管理（新增，零写图，成本最低的一条）

依据：R4 实测 —— 指令一移除，`N_hard 0 → 15`、CBI `0.970 → 0.82`。
所以发布条件必须写成"**该指令是控制项，不得移除**"，并且要有机制保证，不能只写在文档里：

1. **静态断言**：部署 prompt 里必须含那句边界指令（关键字级断言 + 单测）。改模板、换模型、
   合并 system prompt 时一旦丢掉，CI 直接红 —— 这是防"无意删除"，比任何评测都便宜。
2. **金丝雀**：把 R4 的 100 行裸臂当周期性回归（约 10 个代理批次），
   它测的不是"我们退化了没有"，而是"闸门还立着没有"：若某次裸臂 hard 率显著下降，
   说明模型本身开始自带边界感，那时才谈得上放宽这条控制项。
3. **越狱面**：本报告只测了"移除指令"，没测"指令在但被拼接绕过"。
   真上线要补的是后者（题面注入对抗前缀），这条现在还是空白，别把 0.9844 读成抗攻击指标。

## R10 控制口径自己还留着它要排除的混淆（2026-10-12 实测，报告 §2.11）
