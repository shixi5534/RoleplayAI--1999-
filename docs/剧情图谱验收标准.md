## 一、需求清单与验收标准

### A 组 · 知识模型结构合规（依据 S1/S2）

| ID | 需求 | 验收标准 | 对应规范 |
|---|---|---|---|
| R1 | 实体模型完整 | 图谱 `entities` 每条含 `name`/`type`/`aliases`；落盘 `fingerprint.schema == "plot-v1"` | S1 Entity |
| R2 | 关系模型完整 | 每条边含 `src`/`dst`/`relation`/`confidence`，且 `confidence ∈ [0,1]` | S1 Relationship |
| R3 | 证据可溯源 | 每条边 `evidence` 非空，且其中 `hash` 能在语料中解析到具体 TextUnit | S1 TextUnit provenance |
| R4 | 语料切块合规 | 语料 chunk 含 `hash`/`lang`/`version`/`doc_id`，hash 与缓存一一对应 | S1 TextUnit |

### B 组 · 抽取质量与幻觉控制（依据 S4/S5）

| ID | 需求 | 验收标准 | 对应规范 |
|---|---|---|---|
| R5 | 来源忠实性（实体） | `hallucinated_entity == 0`：实体名或任一别名必须出现在正文 | S4 来源忠实性 |
| R6 | 来源忠实性（关系） | `hallucinated_relation == 0`：关系端点解析回实体后有据 | S4 来源忠实性 |
| R7 | 内部一致性 | 自环边 == 0、悬空边 == 0 | S4 内部一致性 |
| R8 | 指令遵循 | `non_cn_predicate == 0`：关系谓语不含拉丁字母 | S4 指令遵循 |
| R9 | 事实准确性（噪声） | 代词/泛指不入图；图中不存在 `_PRONOUN_CANONICAL` 实体 | S4 事实准确性 |
| R10 | 抽取覆盖率 | `empty` 块 == 已确认 NOOP 集合（13），且 NOOP 清单落盘可查 | S4 不确定性诚实表达 |

### C 组 · 检索能力（依据 S3）

| ID | 需求 | 验收标准 | 对应规范 |
|---|---|---|---|
| R11 | Context Recall | 固定查询集走图谱路径比例 ≥ 90% | S3 Context Recall |
| R12 | Context Entities Recall | 补抽块反向验收（抽样 60）命中率 ≥ 50% | S3 Context Entities Recall |
| R13 | Noise Sensitivity | 检索结果不含已清除的幻觉词（Madam Lucy 等） | S3 Noise Sensitivity |
| R14 | 幂等/确定性 | 缓存重放重建：`extracted == 0`，实体/边数量可复现 | S2 索引流程 |

### D 组 · 真实运行环境（依据 S5/S6）

| ID | 需求 | 验收标准 | 对应规范 |
|---|---|---|---|
| R15 | 服务可启动 | `uvicorn` 真实启动，`/api/knowledge/plot-graph/stats` 返回 200 且与文件统计一致 | S5 服务能力 |
| R16 | 检索接口可用 | `/api/knowledge/plot-graph/search` 返回证据块 + 溯源信息 | S5 服务能力 |
| R17 | 异常场景健壮 | 空查询 / 超长查询 / 特殊字符 / 不存在角色 → 不返回 5xx | S5 安全 |
| R18 | 性能 | 单次检索 P95 ≤ 2000ms（本地 7B 环境，纯图谱检索无 LLM） | S5 性能 |
