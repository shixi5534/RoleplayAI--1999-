## 3. 关键设计决策（已定）

1. **渲染选型**：首选 `pixi-spine`（@esotericsoftware/spine-pixi 4.2），复用宠物页已有 PIXI 栈共享 GL 上下文；`spine-player.js` 为降级 fallback（混排能力降级为整段切换）。
2. **默认窗口 320×420**，三档断点 S/M/L（<380 / 380~460 / >460）。
3. **人偶定位**：水平居中、垂直居中偏下；头顶留白 = 窗口高 8%（硬约束，给气泡留位）；脚底落地线 = 下沿 −16px；缩放 = min(舞台可用高/骨骼自然高) × 0.92。
4. **状态机**：九态（闲置/漫步/拖拽/聆听/思考/说话/勿扰/锁位/睡眠），其中勿扰与锁位为**正交修饰态**，与主状态叠加，避免状态爆炸。
5. **勿扰/锁位**：透明度 0.55 / 虚线框 + 锁位 chip + 长按 1.5s 解锁。
6. **图标**：emoji 全退役，换 SVG 描边 1.5px 金铜（16 个必备图标，Lucide 同语义）。
7. **输入条焦点取舍**：展开抢焦点 + 8s 自动收起（已接受）。

## 4. 设计 token（视觉风格板 §11 可直接复制）

两份文档全部通过 CSS 变量对齐，核心 token 一览（完整清单见风格板 §11 `:root` 代码块）：

- 色彩：`--fg/--fg-dim/--fg-faint/--accent/--accent-dim/--accent-glow/--accent-bright/--ok/--danger/--warn/--bg-panel(+hover/active)/--line(+strong/faint)`
- 字体：`--font-serif/--font-mono` + 7 级字号 `--fs-chip(10px) → --fs-heading(18px)` + 3 档行高
- 间距：4px 栅格 `--space-1(4px) → --space-6(32px)`
- 圆角：`--radius-chip(999px)/--radius-card(8px)/--radius-bubble(10px)/--radius-drawer(12px)`
- 阴影：`--shadow-s1 ~ --shadow-s4`
- 动效：`--dur-fast(120ms) → --dur-xslow(600ms)` + `--ease-standard/enter/exit`
