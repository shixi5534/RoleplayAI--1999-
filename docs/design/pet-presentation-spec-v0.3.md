## 1. 设计原则与范围

### 1.1 五条核心原则

1. **小而美**：宠物是桌面上的"人偶"，不是另一个聊天窗口。默认窗口压到 320×420，信息密度宁低勿高，任何常驻 UI 元素必须回答"它为什么值得常驻"。
2. **一眼识别**：3 秒内让新用户知道"这是无名者、能动、能说话"。品牌条、状态 chip、入场动画、引导滑层共同承担身份表达。
3. **静默陪伴**：宠物默认不打扰。闲置时不闪烁、不弹气泡；视觉指示（思考/聆听/勿扰）全部低亮度、弱动效；勿扰模式一键进入"半透明+静默"。
4. **古风延续**：延续主页"暴雨之前"气质——暗调底、金铜描边、衬线字体。emoji 图标全部退役，换 SVG 描边图标。颜色只允许从既有色板取：`--fg #e8e2d4` / `--fg-dim #9a968a` / `--accent #c9a86a` / `--danger #c96a6a` / `--ok #7fb069` / `--bg rgba(16,22,28,0.92)` / `--line rgba(201,168,106,0.28)`。
5. **隐私优先**：延续 v0.2 §9——仅回环网络、截图/录音内存流转零落盘、contextIsolation + preload 白名单。呈现层任何新组件（如截图分享）不得引入落盘或外发。

### 1.2 范围声明

- 本版覆盖审查报告 P0（#1-4）、P1（#5-10）、P2（#11-20）全部条目，P3 结构性项不在本版。
- **默认呈现形态 = Spine 小模型（人偶）**，素材为 `314701_wmz_s_room.skel` + 512² 贴图；Live2D 大模型降级为"对话模式"，可在设置中切换。这一切换直接根除 P0-1（Live2D 在窄窗被裁头）——小模型 512² 贴图天然适配小窗。
- 改动边界：`frontend/pet.html`、`frontend/js/pet.js`、新增 `frontend/assets/spine/`、主进程仅做必要 IPC 扩展（锁位/勿扰/多屏摆位），不动 `/chat/stream`、`/api/voice/*`、`/api/llm/*`。

### 2.2 渲染技术方案

**决策：首选 pixi-spine（@esotericsoftware/spine-pixi 4.2），spine-player.js 作为降级 fallback。**

理由：
1. 宠物页已加载 PIXI（Live2D 运行时依赖），pixi-spine 与之同栈，可共享 WebGL 上下文管理策略，避免双渲染上下文并存；
2. 宠物需要**编程控制**（animationState 切换/混排/TrackEntry 回调/镜像），pixi-spine 暴露完整 spine-core API；spine-player 是查看器取向，封装层会挡路（v0.2 §11 风险 2 已预警）；
3. Spine 4.2 有官方维护的 spine-pixi 绑定，与素材 `.skel` 版本对齐。

Fallback：若 pixi-spine 加载该 skel 失败（二进制版本不兼容），退回素材包自带 spine-player.js，以其 `SpinePlayer` 实例的 `animationState` 属性做控制；此时混排能力降级为"整段切换"，行走-待机过渡允许 1 帧硬切。两条路径统一收敛在 pet.js 的 `SpinePet` 适配器后，行为接口（walk/idle/emotion/click/sleep）不变。

### 2.3 窗口尺寸适配

- **三档窗口**：默认 **320×420**；可经拖拽右下角或设置切到 420×560、480×640（上限）。Live2D 对话模式强制 ≥420×560。
- **人偶定位规则**（Spine 模式）：模型在舞台内**居中偏下**——头顶留白 = 窗口高 × 8%；脚底落地线 = 窗口下沿 − 16px；水平居中，行走时 flipX 不位移。缩放 = min(舞台可用高 / 骨骼自然高) × 0.92，初始化与 resize 时各算一次。
- 气泡悬浮于头顶留白区，因此 8% 留白是硬约束，不允许模型顶到窗口上沿。

### 2.4 动作映射表（Spine ↔ Live2D 对照）

| 行为场景 | Spine 小模型 | Live2D（对话模式） |
|---|---|---|
| 待机 | `x_ls_jinxian*` 加权池（+ `xiangzishang` 彩蛋） | 现有待机池（8~18s 随机） |
| 行走/漫步 | `target/target2/target3` + 窗口 lerp | 窗口滑动 + 轻动作（退化） |
| 单击 | `djc1/djc2` | 点击区域互动（interact_map） |
| 聆听（录音中） | 待机减速 50% + 麦克风 chip | `playGesture(聆听)` + `e_yihuo` |
| 说话（TTS 中） | 待机微动 + 气泡尾巴摆动 | 说话动作 + 嘴型 |
| 开心 | `hua` / `bian` ⚠️ | `e_weixiao` |
| 难过/低能量 | `cx*` 变体 ⚠️ | `e_nanguo` |
| 惊讶/强情绪 | `bian2/bian3/bian4` ⚠️ | `e_jingya` 等 |
| 睡眠 | `x_ls_he_shang → he_di →（醒）deng` ⚠️ | 90s/5min 分级睡眠 |

双渲染器共享同一张"行为 → 动作"逻辑表，各自取本列实现；未映射到的情绪一律回落待机池。

### 3.2 z-index 与命中优先级

| 层 | z-index | 命中优先级 | 穿透规则 |
|---|---|---|---|
| 模型舞台 | 0 | 6 | 模型包围盒（内缩 12%/6%）外全穿透 |
| 品牌条 | 5 | 7（不响应） | pointer-events:none，永远穿透 |
| 状态 chip 区 | 5 | 5 | chip 本体可悬停（tooltip），空隙穿透 |
| 气泡 | 10 | 4 | 气泡矩形内可交互 |
| 输入条 | 15 | 3 | 展开时整行可交互 |
| 右键菜单 | 20 | 2 | 打开期间矩形内全拦截 |
| 设置抽屉 / 引导滑层 | 30 / 40 | 1（最高） | 打开即全窗可交互，关闭后恢复 rAF 命中测试 |

命中协议沿用现有 `petApi.setInteractive`：rAF 轮询鼠标位置 → 按上表从高到低取第一个命中层 → 有命中即可交互、无命中即穿透（50ms 去抖不变）。

### 3.3 三档断点自适应

| 档位 | 窗口 | 顶栏 | 气泡最大行数 | 输入条 | 适用 |
|---|---|---|---|---|---|
| S（默认） | 320×420 | chip 横排收起为圆点+计数 | 3 行 | 折叠为圆钮 | 日常陪伴 |
| M | 420×560 | chip 横排展开文字 | 4 行 | 折叠，可展开 | 均衡 |
| L | 480×640 | chip 竖排全文字 | 4 行 + 翻页 | 常驻展开可选 | 对话模式/Live2D |

拖拽缩放经主进程 resize IPC，渲染层 `ResizeObserver` 触发 §2.3 重算；断点按窗口宽度取档（<380=S，380~460=M，>460=L）。

## 4. 组件规范

> 通用视觉（全部引用风格板 token）：面板底 `var(--bg-panel)`、描边 1px `var(--line)`、字体 `var(--font-serif)`、正文字号 `var(--fs-body)` / 行高 `var(--lh-normal)`；气泡/卡片/抽屉圆角分别取 `var(--radius-bubble/card/drawer)`；浮起层级阴影取 `var(--shadow-s2)`（气泡）/ `var(--shadow-s3)`（菜单、抽屉）/ `var(--shadow-s4)`（引导滑层等模态）；过渡时长 `var(--dur-fast~slow)` + `var(--ease-standard/enter/exit)`。

### 4.1 气泡

- **用途**：对话回复、OCR 评论、引导台词的唯一文字出口。
- **视觉规格**：锚定窗口顶部居中，**底沿距模型头顶净距 ≥8px，且任何情况下不得遮挡模型面部（包围盒上 40% 为禁区）**；窗口高 <380px 时气泡收窄至窗口宽 76% 并转纵向滚动；常规 max-width 92%、min-width 120px；字号 `var(--fs-bubble)`；最多 N 行（断点表），超出可滚动；小尾巴**永远指向模型头顶**；流式期间打字机效果（逐字追加 + 光标 `▍` 闪烁，`var(--dur-fast)` 节奏）。
- **状态机**：隐藏 → 打字中（流式 chunk）→ 完成 → （可 sticky）→ 隐藏；另设**位置翻转子状态**——默认悬浮头顶区，当头顶空间不足（如模型被拖近窗口上沿）时翻转到模型下方，尾巴方向随翻转但始终指向头顶。完成态底部浮出操作行：**上一句 / 下一句 / 复制 / 朗读 / ✕**（P2-14；SVG 描边图标见风格板图标集）。
- **触发与消失**：`RoleplayChat.send` 流式触发；完成 4~9s（按字数 2200+90ms/字，上限不变）后淡出；点击操作行任意按钮转 sticky 常驻；`Esc`/点击空白/✕ 关闭。OCR 评论首句摘要 + 「详细」折叠（P1-9）。
- **交互**：悬停暂停消失计时；历史翻页维护最近 20 条会话内气泡，`↑/↓` 键同步翻页（P2-19）。

### 4.2 右键菜单

- **用途**：宠物全部主动作入口。
- **视觉规格**：min-width 172px（风格板 §7.2）；分三组，组间 1px 分隔线；每项 = SVG 图标（16px 描边 `var(--accent)`）+ 文字 + 右侧快捷键 hint（灰小字）。
- **分组**：
  - 互动：说话（随机开场）/ 打字聊天（展开输入条）/ 随机动作 / 语音对话；
  - 感知：识别屏幕 / 切换模型（Spine⇄Live2D）；
  - 系统：勿扰 / 锁位 / 静音 / 设置 / 退出（danger 色）。
- **触发与消失**：右键舞台任意处；点击他处、Esc、执行动作后关闭。贴边时向窗内翻转（现有 openMenu 逻辑保留）。
- **交互**：键盘 `↑↓` 选择 + `Enter` 执行（a11y）；emoji 图标全部替换（P2-13）。

### 4.3 设置抽屉

- **用途**：宠物全部配置的唯一入口（消灭"设置页 60% 留白"）。
- **视觉规格**：全窗覆盖层，顶部分组 tab 条（高 32px），内容区单列滚动；控件复用现有 row 样式，range 控件右侧实时显示数值（沿用主页 STEP/RANGE UX）。
- **五个 tab（P2-17）**：
  1. **模型**：渲染器（Spine 小模型/Live2D 大模型）、缩放、入场动画开关；
  2. **对话**：Ollama 模型/地址/温度、自动朗读、闲话来言开关与频率；
  3. **语音**：音色/语速/音量（读写 `roleplay_voice_state`，与主页共享）、按住说话键录制（默认 Alt+Space）；
  4. **屏幕识别**：触发档位（手动/关键词/定时）、关键词编辑器（增删 chip 式）、OCR 语言、节流参数；
  5. **桌面端**：窗口档位（S/M/L）、置顶层级、漫步频率、锁位、多显示器摆位（主屏/副屏/指定坐标）、重置位置、恢复默认。
- **触发与消失**：菜单「设置」/ `Esc` 关闭；修改即时生效 + 控件旁"已生效 ✓"1.5s 微提示。
- **存储归属**：沿用 v0.2 §8——LLM/语音进 localStorage，桌面端特有项经 petApi 写 `userData/config.json`。

### 4.4 状态 chip

- **用途**：把 3 个 7×7 灰点升级为可读的诊断条。
- **视觉规格**：胶囊形（高 20px，风格板 §7.4），= 6px 圆点 + 文字；收起态（S 档）只显圆点+异常计数，M/L 档显文字。颜色：在线 `var(--ok)`、异常 `var(--danger)`、工作中 `var(--accent)` 呼吸、未激活 `var(--fg-dim)`。
- **四枚 chip**：后端 / Ollama / 录音 / 勿扰（勿扰仅开启时显示）。
- **状态机**：每枚 = 正常 ⇄ 异常 ⇄ 工作中；后端/Ollama 探活沿用现有 `/api/llm/ollama/models` 轮询，异常时 chip 常显不淡出。
- **交互**：悬停 tooltip 完整诊断（如 "Ollama 离线 · 127.0.0.1:11434 无响应 · 点击重试"），异常 chip 可点击触发重试。

### 4.5 输入条

- **用途**：桌面端文字对话入口（P0-4）。
- **视觉规格**：高 36px；左 = 输入框（placeholder "说点什么…（Enter 发送 / Esc 收起）"），右 = 发送钮 + 语音切换钮（按住说话，桌面端提示快捷键）。
- **状态机**：折叠（右下 32px 圆钮 ✎）⇄ 展开；L 档可设常驻展开。对话流式期间发送钮转 loading 禁重复提交（沿用 chatBusy）。
- **触发与消失**：菜单「打字聊天」/ 单击圆钮 / 快捷键 `Ctrl+Enter` 展开并聚焦；`Esc` 或发送后 8s 无操作自动收起（可配）。
- **交互**：Enter 发送走 `RoleplayChat.send`（与右键说话同一管线）；展开期间窗口自动转可交互，收起后恢复穿透——**展开时窗口抢焦点，这是已接受的取舍**（见 §12 开放问题 Q1）。

### 4.6 新手引导滑层

- **用途**：首次启动教会五个核心操作（P0-3/P2-18）。
- **视觉规格**：全窗 backdrop（`rgba(0,0,0,.55)`）+ 居中卡片（宽 260px，风格板 §7.6），顶部步骤点 ●●○○○，底部「上一步 / 下一步 / 跳过」。
- **状态机**：隐藏 → 步骤 1~5 → 完成写标记 → 隐藏。任意步可跳过。
- **触发与消失**：`localStorage roleplay_pet_state.onboarded=false` 时入场动画结束后自动弹出；完成/跳过写 `onboarded=true`；设置「桌面端」tab 提供"重看引导"。

### 4.7 勿扰模式

- **用途**：一键进入不打扰状态。
- **视觉规格**：开启后人偶透明度降至 0.55（风格板 §7.7）、待机呼吸动效幅度减半、禁 TTS 发声、漫步暂停；右上角浮现"勿扰"chip（accent 呼吸）。
- **状态机**：正常 → 勿扰（菜单/快捷键切换）→ 正常；勿扰中收到对话请求只显气泡不发声。
- **交互**：菜单「勿扰」切换；可选"30 分钟后自动解除"。

### 4.8 锁位模式

- **用途**：防误拖（游戏/演示场景）。
- **视觉规格**：开启后拖拽手势失效（光标不变 grab），状态区追加锁位 chip（12×12 锁形 SVG `var(--accent)` + 文字"已锁位"，风格板 §7.8）。
- **状态机**：解锁 ⇄ 锁定；锁定中拖拽尝试 → 人偶播 `djc1` 摇头 + toast"已锁定，长按 1.5s 解锁"。
- **交互**：菜单「锁位」切换；**长按人偶 1.5s** 直接解锁（防"锁死找不到开关"）。

## 6. 状态机

### 6.1 全局状态与视觉表现

| 状态 | 动画 | 装饰 | chip | 透明度 | 声音 |
|---|---|---|---|---|---|
| 闲置 | jinxian 待机池 | 无 | 常态 | 1.0 | 无 |
| 漫步 | target 行走 + 窗口 lerp | 无 | 常态 | 1.0 | 无 |
| 拖拽 | 待机悬停帧 | 光标 grabbing | 常态 | 1.0 | 无 |
| 聆听 | 待机减速 50% | 录音 chip 呼吸 | 录音=accent | 1.0 | 无 |
| 思考 | 待机微动 | 气泡打字中 `▍` | 常态 | 1.0 | 无 |
| 说话 | 待机微动 | 气泡尾巴摆动 | 常态 | 1.0 | TTS |
| 勿扰 | 待机呼吸减半 | 勿扰 chip | accent 呼吸 | 0.55 | 禁 |
| 锁位 | 同闲置 | 小锁图标 | 常态 | 1.0 | 同当前态 |
| 睡眠 | he_shang→he_di | 可选"Zzz"浮字 【绘澄】 | 常态 | 0.7 | 无 |

锁位/勿扰是**修饰态**，与主状态（闲置/漫步/聆听…）正交叠加；睡眠是闲置的子状态（90s/5min 分级沿用）。

### 6.2 状态切换表（核心迁移）

| 触发器 | 当前 → 目标 | 视觉/音效反馈 |
|---|---|---|
| 漫步调度器到点 | 闲置 → 漫步 | 播 target 动画，窗口 lerp |
| 到达目标点 / 对话开始 / 录音开始 | 漫步 → 闲置/思考/聆听 | 动画回落待机 |
| 按下拖拽 | 任意 → 拖拽 | 漫步中断 |
| 释放拖拽 | 拖拽 → 闲置 | 动量+反弹，落地吸附 |
| Alt+Space 按下 | 闲置 → 聆听 | 录音 chip 呼吸 |
| 抬起且识别成功 | 聆听 → 思考 | 气泡打字机 |
| SSE 完成 | 思考 → 说话 | TTS 起播 |
| TTS 播完 | 说话 → 闲置 | 气泡计时消失 |
| 菜单开勿扰 | 任意 → +勿扰修饰 | 透明度 0.45 |
| 90s 无操作 | 闲置 → 睡眠（浅） | he_shang |
| 5min 无操作 | 浅睡 → 深睡 | he_di + 透明度 0.7 |
| 任意交互 | 睡眠 → 闲置 | deng 唤醒动画 |

互斥规则（沿用 v0.2）：拖拽/漫步互斥；对话与录音期间暂停漫步调度。

## 7. 新手引导流

5 步滑层（§4.6 容器），每步 = 一句文案 + 一张配图占位（左侧 200×140 示意图槽位，风格板 §7.6）：

1. **拖我移动**——"按住我，拖到桌面任何角落。"（配图：拖拽手势示意）
2. **右键看菜单**——"右键点我，说话、动作、识别屏幕都在这里。"
3. **按住 Alt+Space 说话**——"按住快捷键，直接对我讲话。"（若浏览器降级模式则此步替换为"点底部 ✎ 打字"）
4. **识别屏幕**——"我可以看一眼你的屏幕，聊聊你在做什么。全程本地，不落盘。"
5. **设置抽屉**——"模型、声音、漫步频率，都在设置里。祝你与无名者相处愉快。"

触发：首次启动且 `onboarded=false`；完成/跳过写 localStorage；设置「桌面端」tab 可重看。浏览器降级模式跳过步骤 3 的快捷键描述。

## 8. 可访问性

- **键盘可达**：菜单/设置/输入条/气泡操作行全部 Tab 可达，Esc 逐层退出；右键菜单支持 `↑↓+Enter`。
- **屏幕阅读器**：气泡 `role="status"` aria-live="polite"；chip `aria-label` 含完整状态文本（不依赖颜色）；菜单 `role="menu"/menuitem`；引导滑层 `role="dialog" aria-modal`。
- **对比度**：正文/面板底 ≥ 4.5:1（`--fg` on `--bg` 实测 9.8:1 达标）；chip 文字 10px 例外按大字号图标处理，颜色不单独承担语义（必带文字/图标）。
- **焦点可见**：focus 描边 2px `var(--accent)` outline-offset 2px。
- **动效减弱**：`prefers-reduced-motion` 或设置开关开启后——入场动画改淡入、打字机关闭、漫步改瞬移、呼吸动效静止。

## 9. 隐私与安全延续

沿用 v0.2 §9 全量约定，呈现层新增约束：

- 截图分享（P2-20）合成的 PNG **仅在用户点击"导出"后经系统保存对话框落盘**，不做任何自动保存/上传；
- 引导滑层/帮助气泡不发起任何网络请求；
- 设置 tab 新增的桌面端配置经 petApi 写 `userData/config.json`，字段进 preload 白名单审核；
- 多显示器坐标读取仅用 Electron `screen` API，不外传。

## 12. 开放问题（待用户拍板）

- **Q1 输入条焦点与穿透的矛盾**：输入条展开必然抢焦点、暂停穿透。当前设计接受此取舍（8s 无操作自动收起）。备选：输入条改为独立小弹出窗，主窗保持穿透。——建议维持当前方案。
- **Q2 唤醒词**：审查报告 P1-4 仅要求"提示"，真唤醒词（本地 VAD+关键词）工作量约 2~3d，是否纳入 v1.1？
- **Q3 多显示器默认迁移策略**：副屏断开时宠物自动回主屏原位 vs 记忆每屏坐标？当前设计取前者（简单可预期）。
- **Q4 截图分享的合成范围**：仅"人偶+气泡"，还是含当前桌面背景？含背景涉及整屏截图的二次使用，建议仅前者（隐私面最小）。
- **Q5 ⚠️ 动画语义表**：§2.1 中 20+ 动画语义为命名推测，P0 巡检后若有语义不符（如 `bian` 实为换装），映射表需回修——本版允许文档内小修订，不改章节结构。
