## 五、负样本护栏（需注意）

- **同口径未回退**：基线 10 条负样本（天气 / 写诗 / 算术 / 开会 / 装软件 …）在补抽后**仍全部零注入**。
- 但评测脚本的负样本集已扩到 53 条，其中 **7 条出现注入**（相对论、哈利波特、红楼梦、苹果公司 CEO、巴黎、泰坦尼克号、who is the president）：

| 负样本问句 | 注入块数 | 命中路径 | 图谱中的对应实体 |

| 解释一下相对论 | 8 | mention 4 / semantic 4 | 无对应实体（语义通道） |

**根因**：图谱里存在**通用名词实体**（Paris / President / Harry / 泰坦尼克号等），多为低提及的英文 ASR 噪声实体，通用问句会命中它们。这是被扩大后的负样本集新暴露出来的**既有精度问题**，不是主指标回退（主指标全线上涨）。

**建议**：对 `mentions ≤ 3` 且词表命中的通用名词实体（president / paris / harry / titanic 等）做别名索引降权或加入 `plot_filter_generic_seeds` 词表。

## 六、总结

| 维度 | 结论 |
|---|---|
| 回答正确率 | **提升**：strict_pass +1.67 pt，净多通过 5 题 |
| 可答天花板 | **提升**：ceiling_pass +2.51 pt |
| 多跳 / 推理 | **明显提升**：各 +3.3 pt |
| 召回与精度 | **提升**：recall +1.84 pt、precision +1.02 pt |
| 排序质量（MRR） | **轻微回退 -0.85 pt**（候选池从 5493 边扩到 7582，排序竞争加剧） |
| 延迟 | **变慢**：p95 +47.7 ms（候选池变大） |
| 负样本 | 同口径未回退；新题库暴露出通用名词实体的注入问题 |
| 主要优化方向 | **别名桥缺失（75% 失分）** + 通用名词实体收敛 |

> 结论：本次补抽对检索质量是**净正向**（正确率、召回、多跳能力全线上涨，多通过 5 题），代价是排序 MRR 轻微下降与延迟上升，均属候选池 3.6 倍扩张的规模效应；唯一需要跟进的是通用名词实体带来的负样本注入。
