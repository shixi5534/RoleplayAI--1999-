## 二、管线（可复跑）

脚本已迁入项目：`scripts/voice_pipeline/`（transcribe_whole.py / postprocess.py / correct_zh.py / probe_lang.py）。

1. `transcribe_whole.py` —— 抽音轨 → 带通滤波 → faster-whisper 整段听录 → 句子级切分
2. `postprocess.py` —— 繁简统一（whisper 中文输出会繁简混用）
3. `correct_zh.py` —— 对照英配原文校正中配同音误字，标点规范化

```bash
python transcribe_whole.py --in audio/zh_voice.mp4 --work work/zh_whole \
    --prefix zh --lang zh --model C:/Users/Lenovo/.cache/whisper/medium
python postprocess.py work/zh_whole/zh_whole.json
python correct_zh.py work/zh_whole/zh_whole_clean.json
```

运行依赖（系统 Python 3.14）：`faster-whisper`、`imageio_ffmpeg`（提供 ffmpeg）、`zhconv`。

## 三、关键经验（踩过的坑）

1. **不要强制 `language="zh"`**。英配视频被强制中文转写时，英文台词会被音译成中文乱码
   （如 "那是很重要的,使用了他把鞋子放在鞋子上"）。必须先探测主语言再分别转写。
2. **不要用 ffmpeg `silencedetect` 预切分**。它会把一句台词内部的停顿切成两半；
   BGM 又会掩盖句间静音，导致整句漏识别。改用 whisper 内置 VAD + 词级时间戳按标点断句。
3. **带通滤波削弱 BGM**：`highpass=100,lowpass=4000,loudnorm`。游戏语音视频普遍垫 BGM，
   会严重干扰 VAD 分段。
4. **中英交叉校正**：同一套台词的中英版本互为校对基准。多个关键数字靠英文确认
   （如「1708 条咒语」实为 **17,608**）。
5. **模型选择**：base 质量不足；small 对英文可用但对中文偏弱；**medium 是中文可用下限**。
   本机 CPU int8 下，medium 处理 8 分钟音频约 3 分钟。
6. **Windows 上 HuggingFace 缓存的符号链接会失效**（文件落成 0 字节，报
   `File model.bin is incomplete`）。解决办法：从 `~/.cache/huggingface/hub/models--*/blobs/`
   按文件大小映射复制出实体文件到独立目录，再把本地路径传给 `WhisperModel`。

## 四、用于角色扮演的要点

1. **语气范本优先于事实**：这批台词展示的是她"怎么说"，比"她做了什么"更难得。
   复述往事时她习惯先自我设问，再用精确的名词收尾。
2. **自嘲与留白**：重大创伤只给一句轻描淡写（「那是一场再普通不过的雨」），不解释、不抒情。
3. **数字的精确感**：她会说出「17,608」这样的具体数字，是"档案式精确"的语言特征。
4. **比喻词库**：飞蛾、扑火、光、黑暗的角落、鳞翅的震颤、抽丝剥茧、面具、标本、被打开的门、随波而行。
5. **慎用**：听录文本可能与官方原文有出入。技能名、名词解释等必须逐字引用处，
   以「官方角色情报补充.md」与「核心名词速查.md」为准。

## 五、RAG 检索优化说明

台词文档每个小节都加了 `> 常被问到：……` 引导句，这是本项目 lore 文档的既有惯例
（`核心名词速查.md`、`世界观_暴雨与阵营.md` 等均采用）。实测能显著提升语义检索命中率——
未加引导句的版本 8 条测试问题仅命中 4 条，加上后命中 8 条。

「使用说明」类文字刻意**不放入** `data/lore/`，避免模型在检索时读到"参考文档"提示而破人设。

## 七、双语字幕与配音切换（Phase 3）

- **双配音切片**：中配 48 段 + 英配 85 段（`assets/voice/wu_ming_zhe/{zh,en}/NN.mp3`，共约 6MB）。
  英配槽位由「中英逐句对齐表」（`ZH_EN_ALIGN`，在 cut_voice_clips.py 内）从中文槽位推导。
  对齐表依据语义人工建立（两边时间轴与分段粒度不同，zh 0 ↔ en 0+1 之类）；空对齐表示英文版被
  合并或缺失，此时字幕只显示中文。
- **双语字幕**：`frontend/css/pet-subtitle.css` + `frontend/js/pet-subtitle.js`。
  样式仿游戏内剧情字幕：深棕黑半透明底、金棕细边框 + 左侧金色竖线 + 上缘金色双线装饰；
  中文主行用衬线字体（Noto Serif SC/宋体系）暖白色 `#f2ead6`，英文副行 Georgia 斜体浅金
  `#c9b78c`——中英同时显示。
- **配音切换**：字幕条右上角「中/EN」徽章点击即切换（也可调
  `RoleplayPetVoice.setLang/getLang/toggleLang`），选择存 localStorage（`rp_pet_voice_lang`），
  切换时停掉当前播放并广播 `pet:voice-lang` 事件。字幕恒为双语，与配音语言无关。
- 数据结构：manifest 每条 clip 带 `subtitle:{zh,en}`（与其对齐的另一种语言台词文本），
  `pet:voice-line` 事件 detail 同样携带，供其他 UI（气泡、日志）复用。
