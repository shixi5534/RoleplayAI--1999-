## G. 维护方式

1. **新增词条**：先查灰机 wiki → 确认官方译名 → 写入 `plot_glossary.json` → 同步合并进 `plot_aliases.json`
2. **合并流程**（不破坏现有挂接）：
   ```bash
   # 1. 备份
   cp data/lore/wu_ming_zhe/plot_aliases.json data/lore/wu_ming_zhe/plot_aliases.json.bak_$(date +%Y%m%d)
   # 2. 用 plot_glossary.json 合并（脚本待开发，见联动文档 §3）
   # 3. 零 LLM 重放重建图谱
   ```
