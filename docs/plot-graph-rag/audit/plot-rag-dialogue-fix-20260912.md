# 剧情记忆失效诊断与修复（7 句真实对话）

> 日期：2026-09-12
> 触发：用户实际对话中问「纸信圈儿 / 牙仙 / 诺谛卡 / 芭卡洛儿 / 维尔汀 / 十四行诗 / 阿尔卡纳」，
> 角色（无名者）回答「没接触过 / 记不清 / 不太确定」
> 方式：把 7 句**原样**跑过检索链路（种子 → 分块 → 融合 → 相对门 → 提示词装配），逐句取数与验证
> 前序报告：`docs/plot-graph-rag/audit/plot-rag-audit-20260912.md`（性能/排序/门控/评测基建）

---

## 0. 结论

**不是模型的问题，也不是"资料不够"——资料齐全，但两层原因让它进不了模型：**

1. **剧情图谱层根本没开**（`plot_graph_enabled=False`，`.env` 里连配置项都没有）。
   这 7 个名字里 4 个（纸信圈儿/牙仙/诺谛卡/芭卡洛儿）在手工 lore 资料里 **0 命中**，
   证据全在**英文 ASR 转写**里 —— 关掉剧情层，它们必然"不认识"。
2. **即使打开，还有三个排序缺陷会把答案块丢掉**（本轮逐条实测并修复）。

修复后：**7/7 句的提示词里都带上了含该角色的剧情证据**，离题问句仍然零注入。

## 1. 实测诊断

### 1.1 证据在哪（逐名核查）

| 问句 | 手工 lore 资料（9 篇） | 剧情语料（8358 块） | 人工别名表 |
|---|---|---|---|
| 纸信圈儿 | 0 命中 | **Flutterpage 23 块** | ✅ 有条目 |
| 牙仙 | 0 命中 | **Tooth Fairy 74 块** | ❌ **缺条目**（本轮补） |
| 诺谛卡 | 0 命中 | **Nautica 27 块**（"Nautika" 0） | ✅ |
| 芭卡洛儿 | 0 命中 | **Barcarola 18 / Baccarola 6** | ✅ |
| 维尔汀 | 有 | Vertin 148 块 | ✅ |
| 十四行诗 | 12 次 | **Sonnet 35 块**（"Sonetto" 0） | ✅ |
| 阿尔卡纳 | 有 | Arcana 66 块 | ✅ |

- `lore_wu_ming_zhe.json`（6641 条）里 **6517 条本身就是转写块**（带 BV 号）——英文证据**已经在**向量库里；
  但用户用**中文**问，向量跨语种弱、BM25 不跨语种，取不到。剧情层的价值正是**"中文名 → 英文实体"的别名桥**。
- 结构性数据：**2949 个中文正名实体里 1820 个（62%）的中文名在语料中零命中**，仅 47 个进了人工别名表。

### 1.2 三个排序缺陷（开启后仍会答错的原因）

**F1 提及通道被实体自己的脏别名劫持**（最严重）
`_mention_channel` 对实体的每个名字**等权计数**，而抽取别名里混着无关词：
- 「牙仙」28 个名字含 `doll`(df=21)、`Campbell`(df=13)、`my girl` → 提及 top-3 **全是这些词的块，一块都不含 Tooth Fairy**；
- 「十四行诗」36 个名字含 `Zanetto`/`Sinetto`/`Seneso` → top-1 块只含 `Zanetto`（另一角色）；
- 「阿尔卡纳」含 `Arkanist`（=**神秘学家**，是另一个实体）。
根因即上一轮审计量化的「**建图只过滤正名、不过滤别名**」（图内 2022 条噪声别名）。

**F2 边证据压过提及块**
芭卡洛儿的 top-2 是 `"Could be someplace ten years ago…"`、`"HowOf course, we'd be happy to…"` ——
都是关系证据，对"X 是谁"零信息量。

**F3 `0.85` 相对门把 rank≥3 的答案块丢掉**
实测 5 块只剩 2 块：芭卡洛儿的答案块
`"Baccarola, at last you've graced us with your presence. Henry and I were…"`（0.750）被丢；
阿尔卡纳的 `"That lump of flesh is...Arcana?"`（0.840）被丢。
**根因还有一处分支**：`_filter_chunks` 的「单组提前返回」路径绕过了分组豁免（本轮一并修掉）。

**F4 提示词措辞助推"记不清"**
`_PLOT_HEADER` 旧措辞「片段是语音转写…**拿不准就说记不清，别硬说**」——注入英文碎片时，
模型回"不记得"在它看来是**遵守指令**（角色卡内"记不清"另出现 4 次）。

**F5（已验证无收益，不做）** 边证据块选择：5719 条边里 `evidence[0]` 已有 **95.6%** 含端点名；
改选"含两端名字的证据块"仅提升 1.4%。

## 2. 修复内容

| 项 | 改动 | 文件 |
|---|---|---|
| **P0** | 人工别名表补 `牙仙 → Tooth Fairy / Toothfairy / Miss Tooth Fairy / Ms. Tooth Fairy`（灰机 wiki [牙仙 Tooth Fairy](https://res1999.huijiwiki.com/index.php?curid=3577#2) 页面标题核实） | `data/lore/wu_ming_zhe/plot_aliases.json` |
| **P1** | **别名可信度分层**：可信名 = 人工表别名 ∪ 正名 ∪ 与之**形态相近**的抽取别名（包含关系 / 受限编辑距离 / 共享实义词元）；可疑名降权 `alias_trust_ratio=0.25`，且每实体最多 1 条补位块（防漏召回）。`GraphStore` 新增**仅运行时**的人工别名来源记录（不落盘、不改数据） | `plot_graph.py`、`graph_store.py` |
| **P1 护栏** | ① 变体必须有实义词元——否则称谓片段 `miss` 会因"包含于 Miss Tooth Fairy"成为锚点，把 `Miss Campbell`/`Miss Switchdoctor` 链式拖进可信集（实测踩到的真 bug，可信名从 8 膨胀到 19）；② 短名编辑距离收紧到 1——两字中文名两两距离恒 ≤2（玩偶↔牙仙）会互相误判；③ 链式变体须 df ≥ 3（防二阶漂移） | 同上 |
| **P2** | 实体查询提权机制（短查询命中实体时把提及通道权重抬高）——**默认关闭**，见 §4 消融 | `plot_graph.py`、`config.py` |
| **P3** | 剧情通道**豁免 0.85 相对门**（含"单组提前返回"分支），上游已有条数+字符双预算 | `persona_prompt.py` |
| **P4** | 提示词第 3 条改为「片段里**明确出现过的人名、事件与关系要照实讲**，不要用『记不清』『没接触过』回避」 | `persona_prompt.py` |
| **P5** | `.env` 增加 `ROLEPLAY_PLOT_GRAPH_ENABLED=true`（+ 条数与字符预算） | `.env`（不入库） |

**效果示例（同一句，修复前后）**

|---|---|---|
| 牙仙 | `"That's when humans finally realized how vindictive…"`（含 Campbell/doll） | `"…It looks like the illustration in the old book I read to my son…"`（含 **Tooth Fairy**） |
| 诺谛卡 | 边缘关系块 | `"Nautica? Is that you? That's it! Nautica! That's my name!"` |

## 4. 消融：三个被数据回滚的假设

| 配置 | 严格通过率 | 延迟 p95 | 处置 |
|---|---|---|---|
| 旧打分 + 不做可信分层 + 不做提权 | 45.3% | — | 对照 |
| **+ 别名可信度分层** | **45.3%** | — | ✅ 采纳（真实对话靠它修好） |
| + 名字 df 显著性打分 | 44.3% | — | ❌ 回滚（−1.0pt） |
| + 实体查询提权 | 44.67% | — | ❌ 默认关闭（−0.6pt；A1 关掉它也 7/7） |
| **PPR 20 轮**（终选） | **45.33%** | **176ms** | ✅ 采纳 |
| PPR 40 轮 | 45.33% | 298ms | ❌ 无质量收益、慢 122ms |

> 三条结论已写进代码注释与配置项说明（`plot_name_salience`、`plot_weight_mention_entity`、
> `plot_ppr_max_iter` 的默认值都带**实测依据**），避免后人"想当然打开"。
