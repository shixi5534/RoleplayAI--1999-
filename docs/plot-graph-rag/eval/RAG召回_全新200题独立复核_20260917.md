# RAG 召回 · 全新 200 题生成与独立复核（2026-09-17）

> 目的：300 题集已被反复用于选参（别名桥、融合权重、保底名额、补位重排），
> 存在"对这份题过拟合"的风险。本轮从**未被使用过的候选题**中生成 200 道全新题，
> 作为独立复核集，检验补位重排的收益能否泛化。
>
> 结论：**keep=3 的收益不能泛化**（300 题 +12，新题集 −6），已把默认值改为 **keep=5**
> （两份题集均非负：300 题 +4、新题集 +1）。可泛化的真实增益远小于旧题集上的读数。

## 1. 题集生成

| 步骤 | 数量 |

### 题集结构（与 300 题差异很大，**绝对通过率不可横向比较**）

| 维度 | 新 200 题 | 300 题（参考） |
|---|---|---|
| type | factoid 144 / multi-hop 40 / reasoning 12 / temporal 4 | 200 / 60 / 30 / 10 |
| difficulty | **easy 144 / medium 18 / hard 38** | 150 / 100 / 50 |
| depth | shallow 148 / medium 14 / deep 38 | 170 / 80 / 50 |
| chapter | 1.4=12 / 1.7=7 / 1.9=7 / 1971=6 / 其他 168 | 每章 ≥20 |

剩余候选池本身 easy/factoid 占绝大多数（HAND+AUTO 生成的多为译名题），
这是**池子的客观限制**，不是配额没调好。因此新题集整体偏简单，基线通过率天然更高。

## 2. 评测结果（同一题集、同参数配对）

### 全新 200 题

| 档位 | strict | inject | MRR | p95 | 负样本 |
|---|---|---|---|---|---|
| **off（生产默认）** | 147/200（73.5%） | 140（70.0%） | 0.4622 | 768.1 ms | 54 块 / 7 条失守 |
| on keep=3 | 141（70.5%）**−6** | 134（67.0%）**−6** | 0.4570 | 832.7 ms | 不变 |
| **on keep=5** | **148（74.0%）+1** | 140（70.0%） | 0.4637 | 826.5 ms | 不变 |
| on keep=6 | 147（73.5%）持平 | 140（70.0%） | 0.4628 | 870.8 ms | 不变 |

退化/回升**全部集中在 factoid 组**（144 题）：off 83.33% → keep=3 79.17% → keep=5 84.03%。
multi-hop / reasoning / temporal 三档三档完全不动（45% / 50% / 75%）。

原因：factoid 多为单组证据的简单题，答案证据常出现在第 4–8 名的块里；
keep=3 会把这些位置整体换成余弦更高的候选池块，反而丢掉证据。keep 越大越保守，
只补最后几个名额，就不容易伤到它们。

## 3. 结论与处置

1. **keep=3 的 +12 有一半以上不能泛化**：合并两份题集（500 题）看，
   off = 342、keep=3 = 348、keep=5 = 347，三者几乎持平；
   但 keep=3 的分布是「+12 / −6」（不稳），keep=5 是「+4 / +1」（两份都非负）。
2. **默认值已改为 `plot_rerank_topup_keep = 5`**（`src/roleplay/config.py`），
   `tests/test_plotrag_p0.py` 27 passed。
3. **目标 210（+15）未达成**：可泛化的增益约 +4（300 题）/ +1（新题集），
   远小于在旧题集上读到的 +12。后续若要继续提，应针对
   **multi-hop 组**（新题集 45%、300 题 50%，两集一致地低）做专门优化，
   而不是继续在 factoid 上挪名次。
4. 负样本在全部档位均为「54 块 / 7 条失守 / 新增泄漏 2」，无新增泄漏。

## 4. 复现命令（项目根目录）

```
# 生成新题集（确定性）
.venv/Scripts/python.exe -X utf8 scripts/gen_testset_new200.py

# 基线
.venv/Scripts/python.exe -X utf8 scripts/eval_plot_rag.py \
    --testset data/knowledge/_audit/rag_testset_200_new.json --no-trace --quiet \
    --out data/knowledge/_audit/eval_new200_off.json

# 开启补位（keep=5）
$env:ROLEPLAY_PLOT_RERANK_TOPUP_ENABLED='true'; $env:ROLEPLAY_PLOT_RERANK_TOPUP_KEEP='5'
.venv/Scripts/python.exe -X utf8 scripts/eval_plot_rag.py \
    --testset data/knowledge/_audit/rag_testset_200_new.json --no-trace --quiet \
    --out data/knowledge/_audit/eval_new200_on_k5.json
```

产物：`rag_testset_200_new.json`（题库）、`rag_testset_200_new.md`（人可读）、
`eval_new200_{off,on,on_k5,on_k6}.json`、`eval_300_on_k5.json`。
