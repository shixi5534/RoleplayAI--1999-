## 一、复核方法

对每题的**辅助组**（组 1 及以后）判断：它是否是「回答该问题所必需的证据」。

判据：
1. 辅助组关键词是否**已在题面里出现**（题面已给的信息无需作为必要条件）
2. 辅助组是否为**场景/载具/章节/共现人物**（上下文元素，与答案无因果关系）
3. 辅助组是否为**答案本身或答案的组成部分**（若是，则分组有误，应修正而非删除）
4. 题型是否为**关系题/列举题**（此类题客观需要多个实体）

## 六、源头修正：题集生成器（2026-09-16）

### 定位到的根因

`scripts/rag_testset_candidates_300.py` 里的手工映射表 `SCENARIO_ADD`（34 条）：

```python
SCENARIO_ADD: dict[str, list[str]] = {
    ...
    "洞穴的囚徒篇里海盗船上的歌手是谁？": ["Sotheby", "苏芙比"],   # ← R003 误标来源
    "格蕾塔·霍夫曼的英文名是什么？（今夜星光灿烂篇）": ["Vienna", "维也纳"],
    "诺谛卡的英文名是什么？": ["Antarctica", "南极"],
}

for _cand in SEEDS + HAND:
    _extra = SCENARIO_ADD.get(_cand["q"])
    if _extra and len(_cand["evidence"]) == 1:
        _cand["evidence"].append(_extra)      # ← 把「题干限定词」塞进了证据组
```

设计意图（原注释）是「组1=答案词，组2+=**题干限定词**」——限定词用于锚定场景。
但严格评分口径要求覆盖 `evidence` 的**每一组**，限定词（章节名/载具/同场景人物）
并非回答所必需，混入后直接造成假失败。

### 修正方式

> `evidence` 只承载「答案证据」；题干限定词改放独立的 `scenario_hints` 字段。

| 文件 | 改动 |
|---|---|
| `scripts/rag_testset_candidates_300.py` | `_cand["evidence"].append(_extra)` → `_cand["scenario_hints"] = list(_extra)`；更新文件头字段语义说明 |
| `scripts/gen_rag_testset_300.py` | item 组装时透传 `scenario_hints`（否则生成时丢字段） |

### 验证

```
SCENARIO_ADD 条目 34 → 带 scenario_hints 的题 34
仍有多组 evidence 且原在 SCENARIO_ADD 里的题：0
R003: evidence=[['Regulus','星锑']]  scenario_hints=['Sotheby','苏芙比']   # 误标已消失
```

### 重要说明

- **本次改动只影响「未来重新生成」的题集**。当前基准 `rag_testset_300.json` **未改动**
  （按用户选择），现行评测仍走 `evidence_overrides.json` 的第二口径。
- 若将来重新生成题集，其 `evidence` 天然干净，届时 override 清单可退役。

### 生成过程中修掉的三个坑

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 选题失败「(type × class) 结构无可行解」 | `fill_dims` 用「证据组 ≥2」推断 `hop=multi`——那 34 题的"多跳"标签本就由场景组虚构；移除后配额崩解 | 导出原 dims 显式固定（`SCENARIO_DIMS`，27 条）。判据：题目**客观上确实要两步**（先定位场景再找答案），`hop=multi` 成立；错的只是把场景词当答案证据 |
| 2 | `[save]` 打印出基准路径，疑似覆盖 | 实写正确文件，但打印用了 `OUT_JSON` 常量 | 打印改用 `out_json`（已核查：基准时间戳未变，安全） |
| 3 | 输出 0 条 `scenario_hints` | `finalize()` 用字段白名单重建 dict，编号阶段丢弃该字段 | 显式透传 |

### 三个数字怎么读

- **65.00%**：旧基准原样，含 20 题假失败（题集缺陷），**低估**真实水平。
- **71.33%**：同一批检索结果、换判定口径（剔除冗余组）得到，**含口径修正的加成**，与 65.00% 之间不是"能力提升"。
- **67.67%**：干净题集下的自然结果，**无任何口径加成**，是最可信的真实水平；它介于两者之间，因为新题集仍保留 53 道真多跳题（`covered 31 题`桶即"部分组已覆盖"的真实多跳缺口）。

**结论**：修掉基准缺陷后，真实水平约 **67~68%**；旧基准的 65.0% 低估了约 2.7 pt，而 71.3% 高估了约 3.7 pt。

### 附带观察

新题集上 MRR 与 recall 均高于旧版（0.4024 vs 0.3804、0.3417 vs 0.3150），
而 `chunk_precision` 略降（0.3221 vs 0.3381）——与"多组题从 80 减到 53、单组题占比上升"一致。
