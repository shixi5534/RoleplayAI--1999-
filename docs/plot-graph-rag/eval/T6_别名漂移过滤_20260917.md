## 2. 方法（anchor-drift 公式）

对每个实体的每个**别名** `a`（**正名不参与过滤**）：

- `s_anchor = cos(embed(a), embed(本实体正名))`
- `s_drift  = max over 一跳邻居 N(e) 的 cos(embed(a), embed(邻居正名))`

判定：

- `s_drift > s_anchor + drift_margin` → **drift（漂移别名）**，建议剔除
- `s_anchor < weak_threshold`（默认 `0.30`）→ **weak（弱关联别名）**，建议剔除
- **正名永远保留**（不参与任何过滤）

### s_drift 计算策略（显式声明）

图谱极稀疏：**10406 实体 / 7582 边 / 实测平均度 ≈1.30**。逐别名只对其**候选邻居集合**
（实体的一跳邻居，通常 0~3 个）做点积，而**不是**算全量 `9581 × 10406` 别名×实体矩阵。
内存 `O(别名数)`，计算量 `≈ M × 平均度`，比全量矩阵省几个数量级，结果完全一致。

### 阈值选择依据

- `weak_threshold = 0.30` 为保守下限：bge-m3 非对称检索下，同一实体正名与别名余弦常落在
  `0.30~0.50`；取 `0.30` 可避免误删真实链接面（角色昵称 / 事件别称）。这是保守而非激进阈值，
  已在报告中说明。
- `drift_margin = 0.0` 为默认：仅需 `s_drift` 严格大于 `s_anchor` 即判漂移（判据已够严，
  因 s_drift 来自邻居正名、本身已接近锚点）。

## 4. 验证结果（全部来自本次实跑，非臆造）

### 4.1 负样本侧（53 例 NEGATIVE_CASES，与 `scripts/eval_plot_rag.py` 一致）

| 度量 | p50 | 说明 |
|---|---|---|
| `before_prod` | **0.656** | 真实生产 `ent_vectors` 复现，与生产 `search_entities` top1 完全一致（复现规格所述 0.656） |
| `before_maxagg_all` | 0.709 | 未清洗、按 max 聚合到实体（基线） |
| `after_clean_maxagg` | 0.708 | 清洗后 max 聚合（规格定义的「按 max 聚合到实体」含义） |
| `after_clean_join` | 0.656 | 清洗后忠实重建生产 join 索引（canon / 保留别名[:3] 重嵌） |

> 「按 max 聚合到实体」准确含义 = 实体对查询相似度 = **max over 其各名字向量与查询余弦**，
> 而非对向量做逐元素 max-pool（后者会人为抬高 top1，是错误实现，已规避）。

**负样本闸门 `<0.55`：maxagg 0.708 与 join 0.656 均未通过（`gate_passed=false`）。**

### 4.2 负样本主导性诊断（关键结论，见报告 `negative_dominance`）

- 53 个负查询中，**33 个 top1 命中是其「正名」行**（即实体本身正名向量得分最高）。
  正名不在别名漂移过滤范围内、永远保留，因此这些噪声源**无法被本方法消除**。
- 主导噪声的正名多为泛概念实体：`story / time / Hey / restaurant / charging stations /
  consciousness / advice / Haha / 天气 / 明日 / 当前状况 …`（完整 53 行见报告
  `negative_dominance.rows`）。
- 结论：**负样本 p50<0.55 闸门「单靠别名过滤」不可达**——问题在「正名级泛概念实体」，不在别名。

### 4.3 真阳侧（从 `rag_testset_300.json` 抽 100 题，`retr.link_detailed(q)` 取 exact 命中）

- 抽 100 题得 exact 命中 **138 条**；清洗后丢失 **25 条**；**真阳保留率 = 0.8188**。
- **真阳闸门 `≥0.98`：未通过（`gate_passed=false`）。**
- 最宽松配置（`wt=0.3, m=0.15`）保留率最高仅 **0.8623**；再放宽即开始误删真实链接面
  （角色昵称 / 事件别称落入 weak 区间），保留率不升反降或停滞。
- 结论：真阳保留率 ≤ 0.86，**无法达 ≥0.98**——弱别名中含真实链接面，必须保留。

## 6. 诚实结论：两闸门均「单靠别名漂移过滤」不可达

1. **负样本闸门被「正名泛概念实体」主导**（53 中 33 个 top1 为正名）。别名漂移过滤只删别名、
   不删正名，故即便剔除 1536 个别名，负样本 p50 仍停在 0.656~0.708，远未到 0.55。
2. **真阳闸门受「弱别名 = 真实链接面」约束**，最高仅 0.86（角色昵称 / 事件别称落在 weak 区间，
   删之即丢真阳 exact 命中）。
3. 别名漂移过滤**本身是「对的质量改进」**：它确实剔除 1513 个真漂移别名
   （如 `Madame Boaniche → Madame Bouaniche` 拼写串、`维尔汀 Ms.Timekeeper → Miss Timekeeper`、
   `无名者 → 凯拉/格蕾丝` 串入其它角色等，见报告 `top50_worst`），但**不足以独立把噪声/信号分开**。
4. 满足规格双闸门，必须配合**正名级治理**：删除或降权泛概念实体
   （`story/time/Hey/restaurant/charging stations/consciousness/advice/Haha…`）、
   或重训索引与重设检索阈值（用相对阈值 / 学习排序，而非固定绝对 0.55）。这属于后续任务。
