### 4.2 抽取改用云端强模型（不调用本地模型）

本地 7B 质量灾难级：`entity_precision 0.675` / **`relation_precision` 0.111** / `recall 0.15`；代码注释还记录它违反自己的提示词（把 you/she/we 当实体，污染 20 实体 + 186 边）。

**新架构**：`--build-graph` 从此**只做零 LLM 重放**，抽取由云端强模型产出：

```
cloud_extract.py --dump --batch N --size 40   → _cloud/batch_N.md
        ↓ 云端强模型按规范产出
_cloud/batch_N.jsonl
        ↓ cloud_extract.py --apply
plot_cache/wu_ming_zhe/<hash>.json   → --build-graph（零 LLM 重放）
```

**抽取总量 = 8 358 块**：5 881 新块 + **2 477 旧块一并重抽**（覆盖本地低质量结果）。
**全程只重建一次图谱**——8 358 块全抽完再重建，否则要重建两次。

**产出硬约束**（违反即被静默丢弃）：`type` ∈ 7 类白名单（现有 `_JSON_SPEC` 缺"时间"）；`relation` 必须命中 77 canonical（否定谓语/拉丁/超 8 字一律丢）；`src`/`dst` 必须是本块某实体的 name 或 alias；禁自环；禁代词泛指。

**质量目标**：`entity_precision ≥0.9` / `relation_precision ≥0.5` / `recall ≥0.5`。

### 4.3 命名归一化：**必须联网核查，以灰机 wiki 为唯一标准**

**原则**

1. 所有规范译名的确定**必须联网核查**，不得凭印象、离线推断或考据视频定名。
2. **灰机 wiki（`https://res1999.huijiwiki.com/`）是唯一命名标准来源**。
3. wiki 无据的一律标 `status: pending`，并在 `source` 写明"去哪里能确认"。
4. `inferred`（二手考据/篇章名推定）**不得进入 `alias_flat`**——别名表只允许 `verified`。
