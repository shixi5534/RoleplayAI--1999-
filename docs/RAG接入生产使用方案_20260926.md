## 2. 接入组件（唯一代码改动点——待单独授权）

### 2.1 StaticReranker（最小 diff，~40-50 行）
- **插入点**：`src/compendium_rag/pipeline.py:336-337`（`retriever.retrieve(...)` 返回后、`to_dict()` 前）。
- **行为**：置换式重排——只对 evidence 前 POOL 项换序，**不增删 chunk_id**（grounded/n_evidence 结构性不变，程序化断言随测试走）。
- **配置面**（全部默认关闭，.env 控制）：
  ```
  CMPRAG_RERANK_ENABLED=0            # 总开关，默认关
  CMPRAG_RERANK_POOL=10              # 重排池深（生产 10；30 为实验口径）
  CMPRAG_RERANK_WEIGHTS=cos:2.0,lex:2.0,lex_idf:2.0,lex_title:1.0,orig:1.0,ppr:0.5,has_vec:2.0,seed:1.0
  CMPRAG_RERANK_PROTECT_TOP=4        # 可选保护档：前4名不动，只动 5-6 位边界（缓解 down 翻转）
  ```
- **依赖**：仅 numpy + kb.chunks（词面/结构特征零外部模型、零网络）；特征实现在离线 lab 已验证（403 配置、LOO-CV 196 折）。
- **测试要求**：单测含「关闭时输出与现状逐位一致」「开启时 chunk_id 多重集不变」「down 案例（R080/R300 类）在 PROTECT_TOP 下不复发」。

### 2.2 零代码备选路径（若暂不授权动 src/）
