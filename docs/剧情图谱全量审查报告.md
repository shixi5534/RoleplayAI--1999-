## 三、最重要的发现：Madam Lucy 被系统性硬塞

全量扫描发现 **227 个块**里出现实体「Madam Lucy」，但正文**连 Lucy 这个词都没有**：

- 这是模型对高频角色的强先验，属于**系统性幻觉**，不是偶发错误；
- 后果：清理前「露西」是图谱第一大枢纽（**度 393**），清理后降到 **27**，
  第一名回归「圣洛夫基金会」（度 182）。也就是说她的边**约 93% 是假的**；
- 若不清理，任何以露西为种子的检索都会被这批无证据边污染。

同理被清除的还有「士兵 / 战争 / 学校 / 火山 / 教授 / 那场梦」等**正文里不存在的泛指名词**
——本地模型在英文块里改写中文泛称，属于同一类幻觉。

## 七、408 个空块补抽闭环（已完结）

### 7.1 分诊

`scripts/triage_empty_chunks.py` 以「正文里是否出现**已在图谱 / 别名表 / wiki 表**中的表层形式」
判定真漏抽。首版被 `Don / Will / Here` 等泛词污染（误命中 402 块），
补两道闸后收敛：停用词表 + **文档频率 > 12% 直接剔除**。结果 **266 真漏抽 / 142 合理为空**。
人工抽查那 142 块后发现有实义内容（金预言、潘家园、巴比伦骰子、皮罗斯、曼佩刺杀…），
只是没有既有表层形式，故最终决定 **408 全补**。

### 7.2 补抽与写盘

`scripts/apply_empty_p1..p6.py`，共 **395 块写入 + 13 块确认 NOOP**（战斗语音 / 无专名场景），

### 7.3 补抽内容自检（32 个未落地实体）

### 7.4 顺带修掉的审计规则 bug

`hallucinated_relation` 原判定是「src/dst **字面串**不在正文里」，不解析实体 aliases，
导致「中文正名 + 英文别名」的合法写法被整片误判（回填块 383/395 中标）。
现改为先建端点接地表：端点串按正名/别名解析回实体，再取该实体是否有据；
判定口径同时从「两端都缺失」收紧为「**任一端无据**」，更贴合臆造语义。

### 7.5 别名清洗

`scripts/fix_backfill_alias_hygiene.py` 按图谱归并键 `norm_name`（NFKC + 小写 + 去首尾空格）
去自指 **6** 条、去重复 **98** 条。剩余 2 处 `Dr. S`/`Dr.S`、`mainstairwell`/`main stairwell`
是空格变体，在 `norm_name` 下是不同键且对 ASR 文本有用，**故意保留**。
