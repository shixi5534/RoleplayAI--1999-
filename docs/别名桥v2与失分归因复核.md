# 别名桥 v2 实施与失分归因复核

- 执行时间：2026-09-16
- 目标：按「以灰机数据为标准」为剧情图谱补别名桥，降低 300 题 RAG 评测的失分
- 结论：**桥已建成并验证生效，但对 300 题指标无提升；根因诊断显示该方向本身不是瓶颈**

## 一、做了什么

### 1. 灰机离线词典（`scripts/huiji_lexicon_harvest.py`）
从灰机离线资源（结构化 canon 926 条 + 202 个页面正文，含 84 页原始 wikitext）提取中英对照：

| 规则 | 条数 | 采用 |
|---|---:|---|
| canon.name_table | 552 | ✅ 高可信 |
| canon.npc | 142 | ✅ |
| canon.character | 123 | ✅ |
| wiki.DisplayTitle | 56 | ✅ |
| wiki.cb（正文 `中文{{cb|English}}`） | 51 | ✅ |
| wiki.displaytitle_small | 50 | ✅ |
| wiki.plain（正文紧邻并列） | 457 | ❌ **弃用** |

产物：`data/lore/wu_ming_zhe/huiji_lexicon.json`（中文条目 913 / 英文 855，逐条记录来源规则）。

`wiki.plain` 弃用理由（实测）：错配率高——`级增幅 ↔ APPLe`、`UTTU ↔ 阅读访谈`、`UFO ↔ 猎人`、`狼群 ↔ Pavia`（此条实为正确，但无法与错误项区分），抓到的多是关卡表头与敌人名，对剧情问答无价值。

### 2. 别名桥 v2（`scripts/huiji_alias_bridge2.py`）
相比 v1 增加两条通路：

| 通路 | 说明 | 例子 |
|---|---|---|
| ① 英文正名 → 中文 | v1 已有 | `Teofil` → 特奥菲尔 |
| ② 中文正名 → 英文（反向） | 新增 | 「阿派朗岛」→ Apeiron |
| ③ 异译（图中译名 ≠ 灰机译名） | 新增 | 图中「塞内塔」← 灰机「扎内塔」 |

通路 ③ 的实现：**正名已是中文的实体，其拉丁别名可参与取证**（如「塞内塔」别名含 Zanetta）。

### 3. 应用结果
- 产出提案 **39 条**，抽查全部正确（Pavia↔狼群、Bkornblume↔柏林以东、Druvis III↔槲寄生、Oliver Fog↔雾行者…）
- 已写入 `plot_aliases.json`（备份 `_archive/plot_aliases_pre_bridgev2_20260916_1755.json`）
- 重建图谱 10406 实体 / 7582 边（别名不改变实体数）
- **检索验证通过**：查询「槲寄生」「柏林以东」「雾行者」均经图谱路径召回含英文 ASR 的块

## 三、根因复核：为什么补桥没用

对 triage 报出的 **96 个「别名桥缺失」缺口组**逐组复核：检查**题面文本里是否出现该组实体的任何名字**（图中正名 + 全部别名 + 证据组关键词）。

| 判定 | 组数 | 占比 |
|---|---:|---:|
| 题面**不含**该组实体任何名字 | **95** | **99%** |
| 题面含实体名（且为误匹配"教师"） | 1 | 1% |

**结论：这些题无论补多少别名都救不回来——因为查询里根本没出现那个实体的名字。**

### 实例

| 题号 | 题面 | 参考答案 |
|---|---|---|
| R002 | 洞穴的囚徒篇中被称作 **standkeeper** 的女性是谁？ | Zanetta（扎内塔） |
| R003 | 洞穴的囚徒篇里**海盗船上的歌手**是谁？ | 星锑（Regulus） |
| R005 | 洞穴的囚徒篇的故事主要发生在什么**载具**上？ | Rockin' Apple 号船 |
| R011 | 在洞穴的囚徒篇里**负责照看乘客健康的牙医**英文名叫什么？ | Tooth Fairy（牙仙） |

这些是**描述性提问**：用户用"海盗船上的歌手"指代角色，用"负责照看乘客健康的牙医"指代牙仙。要答对必须靠**语义匹配或跨句推理**，而不是名字匹配。

### triage 桶名的误导性
该桶的判据是「查询里没出现任何实体名/别名」，但桶被命名为「**别名桥缺失**」（`alias_bridge_gap`），导致优化方向被指向"补别名"。实际语义应该是「**查询未命中实体名**」——它是**症状**，不是**病因**。

## 四、真正的瓶颈：语义检索层不可用

- 配置：`plot_embed_model = 'bge-m3'`、`plot_semantic_enabled = True`
- 运行时报：`剧情语义索引不可用（wu_ming_zhe），本层静默停用：嵌入模型不符（索引 ollama:bge-m3 ≠ 当前 ）`
- 实测：数据目录中**不存在语义索引文件**

即：描述性提问唯一能救的通道（向量召回）当前是**关闭**状态。这 79 题属于语义可解、但语义层未启用。

## 五、建议的下一步

优先级从高到低：

1. **启用语义检索层**（最高收益）：构建或对齐 bge-m3 语义索引，让"海盗船上的歌手"这类描述性查询能召回候选块。预期能覆盖相当比例的 79 题。
2. **查询扩展 / 关键词抽取**：从题面描述性短语（standkeeper、海盗船上的歌手）生成候选实体名再走图谱。
3. **题集标注复核**：R003（答案星锑、证据组 Sotheby/苏芙比）、R006（答案保利娜、证据组 Sotheby/Regulus）等存在证据组与参考答案不一致的情况，需确认是否题集本身标注有误。
4. 别名桥可保留（39 条已入库、质量合格），但**不应作为提升 300 题的主攻方向**。
