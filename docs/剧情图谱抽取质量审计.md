## 四、审计触发的修复

**F1 · is_noise_entity 里中文分支 `re.search(CJK) → return False` 排在代词判定之前，导致「我们/他们/她们」这类中文代词无法被过滤（图内已混入实体「我们」，缓存 16 块 18 个）。**  
→ 处置：把 _PRONOUN_CANONICAL 判定提到 CJK 分支之前，并在集合里补入她/他/它/你/我/我们/他们/她们/它们/大家/某人 等中文代词与泛指。  
`src/roleplay/core/knowledge/plot_graph.py`  

**F2 · Kiperina 被转写成 Keeperina 后译名为臆造的「凯瑞娜」，与灰机 wiki 的「库珀花环」不一致，导致同名角色分裂。**  
→ 处置：以 wiki_zh_en.json 为准，把 Kiperina/Keeperina 收敛到「库珀花环」。  
`data/lore/wu_ming_zhe/plot_aliases.json`  

**F3 · 自环边（Marianne→Marianne）能写进图谱，属无效结构。**  
→ 处置：建图时丢弃 src==dst 的边。  
`scripts/fix_pronoun_entities.py（顺带清理）+ 建议 build_plot_graph 增加自环过滤`
