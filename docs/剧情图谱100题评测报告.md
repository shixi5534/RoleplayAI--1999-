## 四、结论

1. **图谱路径是主通道**：98% 的查询通过图谱路径返回内容，说明检索器与图谱的衔接正常。
2. **实体/别名题表现良好**：实体题 sem@5 84%、pair_hit 100%（返回边必含目标实体）；别名题 sem@5 73%。
3. **关系题的瓶颈是 top-k 而非召回**：严格命中率随 k 单调上升（top-5 55% → top-10 64% → top-20 71%），说明正确证据存在于候选池中，只是排序竞争激烈（7582 条边 / 9021 个块）。
4. **严格判定会低估召回**：同段剧情在语料中有多块提及，按 evidence 单一 hash 判定为不命中，但返回块实际含有可用信息。
