## 判定：不落地。原因（重要，这是对文献结论的边界修正）

1. **PPR 信号在本项目已被 mention/edge 两通道承载**：`_mention_channel` 的 targets
   就是 PPR 分数（seed_factor 1.0 / 邻居 0.5），edge 通道也从 PPR 传播结果取边。
   在语义通道再乘一次 PPR 权重 = **同一信号重复计入**，语义通道退化成 mention 的
   回声，丢掉 cosine 的独立信息量 → strict 与 inject 双降。
2. **HippoRAG 的结论不能直接迁移**：它是"PPR + dense"两通道浅架构，PPR 与 dense
   互为唯一信号源，所以 PPR 引导 dense 有增益；我们是五通道富架构，信号已经
   通道化分工。**富架构里往已有信号的通道上重复加权 = 负优化**——这与 T1（CE 精排
   挤占）、整体重排（inject −26）、同义改写（0 收益）同属一个家族：
   **语义通道的 top-5 名额给"与既有通道正交的 cosine 信号"才是它的价值**。

## 对路线图的修正

- T4 关闭（不再尝试 PPR×dense 加权变体）。
- "对齐 HippoRAG"的正确姿势修正为：**不是复制它的融合方式，而是检查我们的通道
  分工是否已覆盖它的信号面**——PPR（mention/edge ✓）、dense（semantic ✓）、
  词面（lexical ✓）、高层摘要（chapter ⚠️ 弱，见 T5）。
- multi-hop 提升的希望收敛到：T5（章节摘要节点）、T7（补名，上界已证）、T8（分解路由）。
