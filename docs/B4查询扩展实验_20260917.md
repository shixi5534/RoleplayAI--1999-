# B4 查询扩展：天花板 +25.67 pt，但三种自动实现全部失败

- 时间：2026-09-17 01:17 – 08:00
- 题集：`rag_testset_300_clean.json`（300 题），生产口径 `top=6+2=8`、注入预算 2400
- 判定：一律以 `inject_pass` 为准（`strict_pass` 可被多返回块灌水）

## 一、为什么做 B4

前面所有方向都已证伪（调参 / 扩大候选 / LLM 重排 / Cross-Encoder / P1-1），
而 B4 有最硬的一条线索：

> 96 个缺口证据组里 **95 个的题面不含该实体的任何名字**
> （「海盗船上的歌手是谁」→ 答案 星锑；「负责照看乘客健康的牙医」→ 牙仙）

## 二、先测天花板：+25.67 pt（作弊上界）

`scripts/diag_b4_ceiling.py` —— 把每题 evidence 的全部关键词直接拼到 query 后面，
模拟"完美查询扩展"：

| 指标 | 现状 | 完美扩展 | Δ |
|---|---:|---:|---:|
| **inject_pass** | 0.6200 | **0.8767** | **+25.67 pt（+77 题）** |
| strict_pass | 0.6767 | 0.8867 | +21.00 pt |
| top2_hit | 0.4133 | 0.7067 | +29.33 pt |

分层：单组题 +27.13 pt｜多组题 +18.87 pt。

**这是全天所有方向里最大的空间**（对比：调参 ~0、扩候选 ~0、CE −1.7、P1-1 前提不成立）。

⚠️ 这是**上界**：真实 B4 必须在**不知道答案**的前提下猜出实体。本测试只回答"天花板有多高"。

## 三、三种自动实现，全部失败

### ① 现有语义实体链接（bge-m3）—— 最多 +1 题

**先发现一个真 bug**：`plot_semantic_link_*` 在生产中**从未生效**。

```python
# plot_graph.py:1436
if not seeds and self.semantic_link_top > 0 and (
        self.semantic_link_min > 0 or _want_margin):
```

生产 `semantic_link_min = 0.0`，而 `_passed` 的过滤条件又要求 `semantic_link_min > 0`
⇒ 整段短路。**实测印证**：`link_top` 3→10→20，全部指标**逐位不变**（Δinject ±0）。

把它真正打开（`link_min` 设正值）：

| 配置 | inject | Δ | strict |
|---|---:|---:|---:|
| 基线（min=0，同批次） | 0.6200 | — | 0.6767 |
| min=0.2 | 0.6200 | ±0 | 0.6800 |
| min=0.35 | 0.6200 | ±0 | 0.6800 |
| min=0.5 | 0.6233 | **+0.0033** | 0.6833 |
| min=0.35 + top=10 | 0.6233 | +0.0033 | 0.6833 |

⇒ 最多 +1 题。原因与全项目其它结论一致：**bge-m3 认为"错实体"更像答案**。

### ② 实体级伪相关反馈（PRF）—— −2 ~ −9 pt

`scripts/diag_b4_prf.py` —— 不依赖外部知识的自扩展：
第一轮检索到的块 → `link_detailed(block.text)` 抽实体 → 拼进查询 → 第二轮。

| 扩展实体数 | inject | Δinject | top2_hit |
|---:|---:|---:|---:|
| 0（基线） | 0.6200 | — | 0.4133 |
| 1 | 0.6000 | **−2.00 pt** | 0.4033 |
| 3 | 0.5600 | **−6.00 pt** | 0.3833 |
| 5 | 0.5300 | **−9.00 pt** | 0.3533 |

**剂量相关地变差**——扩得越多越糟。原因清楚：第一轮检索到的块**本身就是错的**
（所以才失分），用它们抽实体等于把噪声灌进查询，还会自我强化。

### ③ LLM 从正典名单识别实体 —— 命中率 15%

`scripts/diag_b4_llm_link.py` —— 把 `huiji_canon.json` 的
**141 角色 + 184 NPC（带身份/版本/章节）** 交给 qwen2.5:7b，
让它为每道题挑 Top-3 最可能的角色：

**Top-3 命中真实答案：9/60 = 15.0%**

样本说明问题：

| 题 | LLM 选中 | 真值 |
|---|---|---|
| R002 | 命名日, 命名日, 命名日 | Zanetta |
| R016 | 维尔汀, 牙仙, 瑞恩馆长 | Zanetta |
| R026 | 星锑, 维尔汀, 牙仙 | Teofil |
| R063 | J, 77, 朵拉 | Horropedia/恐怖通 |

⇒ **qwen2.5:7b 对这部作品的设定不熟**：不管问什么都在重复挑同样几个熟脸
（维尔汀/牙仙/星锑），R002 甚至重复输出同一词；无法把「递交钥匙的管家」映射到 Zanetta。

## 四、结论

**B4 的天花板是真的（+25.67 pt），但它需要「懂设定的实体链接」，本环境没有可用来源。**

| 实现路径 | 结果 | 原因 |
|---|---|---|
| ① bge-m3 语义链接 | +1 题 | 向量认为错实体更像答案 |
| ② PRF 自扩展 | −2 ~ −9 pt | 第一轮块本身是错的，噪声自我强化 |
| ③ LLM + 正典名单 | 识别率 15% | 本地 7b 不懂该作品设定 |

⇒ **不建议继续在"自动猜实体"上投入。**

## 五、若要继续，只剩这三条（都需外部条件）

| 方案 | 需要什么 | 预期 |
|---|---|---|
| 换懂设定的 LLM（GPT-4 级 / 该作品微调模型）做实体识别 | 外部 API 或更大模型 | 识别率若到 50%+，按天花板折算约 +10 pt |
| 人工/半自动术语表：描述短语 → 实体 | 人工标注成本 | 覆盖有限，但准确率 100% |
| 用灰机 wiki 正文（已被 CF 拦，29 个专名待抓）补全正典描述 | 过 CF 验证 | 给 LLM 提供身份描述，提升识别率 |
