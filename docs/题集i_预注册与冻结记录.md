## 7. 五臂结果（full 模式主口径，L1=全量 T1 n=185）

**预检（零检索）：各臂补名 100% 可 resolve，无臂被喂垃圾名 → 五臂横向公平。** empty 0 picks；random 573（282 题非空）；alias 554（214 题）；strong 711（279 题，均值 2.55/题，信号最强）；vector 名取自 entity_index 正名，天然可 resolve。

`_iset_eval5.py`（top_k=10 单次运行、按 rank 统一派生 hit@6/hit@10，横切全臂）产物 `data/compendium_rag/reports/eval5_set_i.json`：

| 臂 | hit@6 | hit@10 | MRR | grounded |
|---|---|---|---|---|
| empty | 0.8919 | 0.9243 | 0.661 | 1.000 |
| random | 0.7946 | 0.8919 | 0.5534 | 1.000 |
| alias | 0.8703 | 0.9135 | 0.6278 | 1.000 |
| vector | 0.8432 | 0.8973 | 0.6078 | 1.000 |
| **strong** | **0.9027** | **0.9459** | **0.7099** | **1.000** |

**预注册闸门逐条判定（full/L1）：**

1. L1 全量 hit@10 ≥ 0.70 → **0.9459 ✅**。
2. strong−empty ≥ **+5pt** 且 McNemar p<0.05 → **+2.16pt（hit@10）/ +1.08pt（hit@6），McNemar b=7 c=3 p=0.3438** → **未过**（提升方向为正但幅度与显著性均不达标）。
3. strong 优于 random（>0）→ **+5.40pt，McNemar p=0.0213 ✅（显著）**。
4. grounded=1.000 全臂 → **✅**（安全线未破）。
5. 逐题 up/down（hit@10, strong vs empty）→ **up(7)**：i053,i076,i087,i157,i168,i227,i334；**down(3)**：i141,i228,i285。

**诚实结论：** 强模型补名在 L1 是**五个臂中全指标最优**（hit@6/hit@10/MRR 均第一），且**显著优于随机补名**（p=0.021）——证明「识别质量」本身有效，方向为正、机理成立（MRR +0.049 说明命中的 gold 排名整体上移）。但**未过预注册的主闸**（strong−empty ≥+5pt & p<0.05）：仅 +2.16pt、p=0.34。**根因是基线天花板**——empty 零补名已达 0.924，距满分仅 7.6pt，+5pt 需 strong≥0.974，近乎不可达；这是预注册把「绝对增益」定得偏严的产物，非补名被证伪。对照臂 random/alias/vector 全部 ≤ empty，唯 strong 越过 empty，进一步佐证盲识别的信号真实性。**判负于「绝对提升闸」，判胜于「优于随机/噪声注入」的横向对照。**

**L2（仅报告，非闸）：** MULTI hit@10 strong=empty=0.9545（并列，random 最低 0.909）；T2i hit@10 strong=0.7759 **低于** empty 0.7931——定义型题补名无益、反被扰动拖累（邻域稀薄，§6 覆盖 0.3621）。

**unanswerable：** 题集 i 只发布 answerable 层（U 层未发布），无 unanswerable 子集，故「不升」约束本集 N/A（安全线以 grounded=1.000 为准，已过）。

**graph_only 对照档（纯符号通道，不吃向量扰动）L1 hit@10：** empty 0.773 ｜ random 0.6703 ｜ alias 0.7622 ｜ vector 0.7135 ｜ **strong 0.8703** → **strong−empty = +9.73pt**（远超 full 模式的 +2.16pt），strong−random = +20pt。hit@6 同向（strong 0.773 居首）。

**修订后的完整结论：** 补名信号**真实且强可达**——在无嵌入扰动的纯符号通道增益 **+9.73pt**；full 模式仅 +2.16pt 的**根因是「把补名追加进 query 再整体嵌入」这一步扰动了向量通道**（§3.2 native 线同样显示：graph_only 补名 +2、full −11，扰动主源即向量融合），并非识别本身无效。据此：(1) 主闸（full/L1 +5pt & p<0.05）**未过**（+2.16、p=0.344）；(2) 但 strong 在两种模式下**全部指标（hit@6/hit@10/MRR）居五臂之首**、且显著优于 random（full p=0.021 / graph_only p 更小）——**路线方向被证真，被证伪的只是「原样接入 full 向量通道」的用法**。**可执行改进（后续任务）：补名只入符号通道（graph 权重/PPR 种子），或嵌入时用原 query 而补名仅走 link/mention，避免污染向量通道**——预期把符号通道 +9.73pt 的大部分带回 full 口径，届时重跑五臂复核主闸。
