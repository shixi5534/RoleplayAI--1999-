02The Clockwork

发条装置六个工位，一轮咬合

每一轮对话，这台机器都要走完六个工位。齿轮咬合的顺序，就是她「记得」的顺序—— 而最后一站会把结果送回第一站，于是记忆开始累积。

STATION 01

情感

识别 15 类情绪，决定这一轮她用什么表情、动作和节奏开口。情绪在前，语义在后。

STATION 02

检索

向量库 + BM25 混合召回，从 2477 段剧情切片里捞出与这句话有关的碎片——只取一两点。

STATION 03

角色卡

Character Card V2 人设 + 每轮置底的 3–5 条核心锚点，长对话里防止角色漂移。

STATION 04

生成

按请求级配置路由到 本地 Ollama 或云端；温度可调，长度按情绪动态压缩。

STATION 05

守卫

复读与出戏守卫：同一句式、同一个意象用过就不再重复；被追问身份时不许跳出角色。

STATION 06

记忆

会话摘要、长期记忆与画像提取落盘。下一轮回到工位一——她开始记得你说过的话。

↺ 回到 STATION 01 · 记忆累积

07Cold Start

冷启动三条命令，她就开始说话

默认就是可跑的：核心单测离线、零外部依赖，不需要任何 API Key。 前端由后端同源托管，不必另起静态服务器。

roleplay-ai — bash 
# 1 · 装依赖（默认 mock provider，无需 Key）
$ python -m venv .venv && .venv\Scripts\activate
$ pip install -e ".[dev]"

# 2 · 跑核心单测（离线、零外部依赖）
$ pytest

# 3 · 起服务 —— 前端由后端同源托管，打开即可对话
$ uvicorn roleplay.main:app --host 127.0.0.1 --port 8000

COLOPHON · 关于这一页

这是一份静态设计稿：页面不发起任何后端请求，所有数字都来自仓库里的真实文件， 原声播放读取的是 frontend/assets/voice/ 下的本地静态音频。

视觉方向取自角色本身——她接受过十四天心理训练，被植入「发条装置」， 大脑会随不同光源自动生成对应人格与记忆，如飞蛾扑火。 于是这一页做成一间被打开的昆虫学标本室：分类的器械压在一个人身上，而人拒绝被钉住。
